# Code of Conduct

DURA adopts the [Contributor Covenant version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

The full text and the standards it sets are at the link above.

## Reporting

Concerns about behavior in DURA's repositories, issues, pull requests, or any other community space can be sent to **conduct@durwoodstudios.com**.

Reports are read by Dustin Snellings (project owner) and treated as confidential. We respond within 5 business days.

## Scope

This code applies across all DURA-affiliated spaces: the repository, issue tracker, pull requests, discussions, Discord (when launched), and any in-person or online event using DURA's name.
