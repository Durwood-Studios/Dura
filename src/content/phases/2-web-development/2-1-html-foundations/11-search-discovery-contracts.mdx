## Why this matters

A useful public lesson exists, but its title is “Page” and no public link leads to it. Search discovery begins with understandable public content and crawlable navigation, not a promise to manipulate rankings.

## Start with something familiar

A library catalog needs a meaningful book title and a shelf location. A search system also needs a way to discover a page and interpret its subject; neither a catalog entry nor a label guarantees popularity.

## The mental model

> Make public pages discoverable and accurately described. Keep access control separate: an indexing instruction is not a confidentiality mechanism.

## The mechanism

Search-engine optimization, or SEO, includes helping search systems discover and understand public pages. A descriptive HTML title, a meaningful main heading, ordinary links and useful content establish a clearer subject than repeated keywords. A meta description can offer a summary, but a search engine may choose other text for its result snippet.

This complete small page uses an ordinary link and an accurate description:

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Read a Python sensor row — Field Notes</title>
  <meta name="description" content="A worked example distinguishing a missing RPM field from a measured zero.">
</head>
<body>
  <main>
    <h1>Read a Python sensor row</h1>
    <p>A missing field is an input error; a zero reading is valid data.</p>
    <a href="/lessons/python-rows">Read the worked example</a>
  </main>
</body>
</html>
```

The destination is an illustrative route that an actual site must implement; the document itself renders as-is. On a real site, verify the link resolves to the intended public content and that the response is successful rather than a soft error page with status200. Canonical URL declarations are hints about a preferred version among duplicates; they are not redirects or a mechanism to hide private pages.

A robots crawling rule and a noindex instruction serve different purposes. A crawler may need access to a page to see noindex. Neither replaces authentication and authorization for private learner records. Do not publish private content and rely on obscurity, robots.txt or a guessed search delay.

A useful review checks rendered content, titles, links, status codes and indexing intent. It does not promise a ranking position: search systems choose their own results and may take time to revisit changes.

## Practice

A team blocks a private report in robots.txt but serves it without authentication. Has it protected the report?

<details><summary>Compare the reasoning</summary><p>No. The content is still accessible to anyone who requests it. Enforce authorization at the serving boundary; crawler instructions are not security controls.</p></details>
