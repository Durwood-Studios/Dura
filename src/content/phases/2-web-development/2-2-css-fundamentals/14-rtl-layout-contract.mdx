## Why this matters

An interface translates its words but leaves navigation order, spacing and mixed-direction identifiers confusing. Internationalization includes writing direction and layout behavior, not only replacing strings.

## Start with something familiar

A map can be labeled in another language while its arrows still point to the wrong destinations. Directional layout must preserve meaning rather than mechanically mirror every visual element.

## The mental model

> Use semantic direction and logical layout properties, and isolate mixed-direction content. Test reading order, focus order and icon meaning rather than assuming every element should be reversed.

## The mechanism

HTML lang identifies language; dir identifies base text direction. They are separate attributes. For a right-to-left page, dir="rtl" establishes direction, while logical CSS such as margin-inline-start and padding-inline adapts spacing to the inline flow. Keep the DOM in a meaningful reading sequence so keyboard and assistive-technology order remains understandable.

```html
<!doctype html>
<html lang="ar" dir="rtl">
<head><meta charset="utf-8"><title>Direction fixture</title></head>
<body>
  <main>
    <h1>حالة الطلب</h1>
    <p>رقم الطلب: <bdi>ABC-123</bdi></p>
    <button type="button">متابعة</button>
  </main>
</body>
</html>
```

The bdi element isolates the unknown-direction identifier from surrounding text. The Arabic fixture labels an order status, order number and continue button; production translation still needs a fluent reviewer. Do not concatenate translated sentence fragments around values when grammar or word order can change.

Directional arrows tied to navigation may need mirroring, while logos, photographs, media playback conventions or a chart’s data meaning should not be reversed blindly. Decide by semantics. A left/right physical property may still be appropriate for a physical coordinate diagram, but use logical properties for ordinary text-flow spacing.

Test a narrow viewport, long translated text, mixed Arabic/Latin identifiers, numbers, keyboard traversal and zoom. A visually mirrored flex row with unchanged DOM order can produce a mismatch between what a sighted user sees and how focus moves. Record the expected order instead of solving layout only with row-reverse.

The example is a static direction fixture, not a complete localized product. Add locale-aware dates/numbers and complete message translations using the earlier internationalization contract, with human review for language and domain meaning.
