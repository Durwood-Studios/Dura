## Why this matters

Every modern app talks to other apps. Your weather app talks to a forecasting service. Your fitness tracker talks to a cloud sync service. Your favorite game talks to a leaderboard server. The thing they're all using is an **API** — and once you understand what one is, you can connect almost anything to almost anything else.

## Start with something familiar

Imagine ordering from a menu. You use the offered names and choices without entering the kitchen or controlling the recipe.

## The mental model

> An API defines how to request an operation; a data format defines how the request or result is represented.

## What an API actually is

API stands for **Application Programming Interface**. The plain-English version: it's a contract that says "if you ask me for X in this exact way, I'll give you Y in this exact format."

Think of it like a restaurant menu. The menu doesn't show you the kitchen — it tells you what you can order and what you'll get back. An API works the same way: it hides the implementation and exposes only the operations you're allowed to perform.

## REST: the most common style

Many web APIs use a style called **REST**. The idea: you ask for "resources" using HTTP methods.

| Method | Means   | Example            |
| ------ | ------- | ------------------ |
| GET    | Read    | GET `/users/42`    |
| POST   | Create  | POST `/users`      |
| PUT    | Replace | PUT `/users/42`    |
| DELETE | Remove  | DELETE `/users/42` |

A REST API URL is a noun. The HTTP method is the verb. Together they describe the action.

## JSON: how the data looks

A common format for exchanging data is **JSON** (JavaScript Object Notation). An object groups named values inside braces; an array lists values inside square brackets. Strings are quoted text, numbers are unquoted quantities, booleans are true or false, and null represents an explicit absence of a value.

```json
{
  "id": 42,
  "name": "Dustin",
  "active": true,
  "skills": ["typescript", "rust", "design"]
}
```

That's the entire format: objects, arrays, strings, numbers, booleans, and `null`. Programming languages provide libraries for reading and writing JSON. You'll use it daily as a developer.
