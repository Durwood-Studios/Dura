## Why this matters

A reminder sent one time too many can annoy someone; a loop that never stops can freeze a page. Recording each repetition makes the stopping rule visible.

## Start with something familiar

Imagine putting three envelopes on a table and counting one each time you stamp an envelope. Repetition needs both a task and a way to tell when enough work is done. A loop repeats a group of instructions.

## The mental model

> For each loop turn, check the condition, run the body if true, and update the count. A false condition stops the loop before the body runs.

## The mechanism

`let` introduces a variable that may be reassigned. In `for (let count = 1; count <= 3; count = count + 1)`, the first part runs once. The second asks whether count is at most three before each turn. The third increases count after the body. On reassignment, `=` stores the right-side result; it does not mean a mathematical equality proof.

```javascript
for (let count = 1; count <= 3; count = count + 1) {
  console.log(count);
}
```

The body displays 1, 2, and 3. After the third turn, count becomes 4. Four is not at most three, so there is no fourth display. The condition is checked before every turn.

## Guided practice

If the condition becomes `count <= 2`, how many display instructions run? If it becomes `count <= 0`, how many run?

You can complete this exercise on paper or in your head, including offline. Predict first; then open the answer.

<details>
  <summary>Reveal the practice answer</summary>

Two instructions run for the first condition. Zero run for the second: the first check already fails because count starts at 1.
