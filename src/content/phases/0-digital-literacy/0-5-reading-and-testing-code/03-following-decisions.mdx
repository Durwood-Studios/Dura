## Why this matters

An age check or stock warning can be wrong for exactly one value: the cutoff. Tracing the decision at that value reveals mistakes that ordinary examples miss.

## Start with something familiar

Imagine a gate with a sign: enter if you have at least three tickets. People with two take one path; people with three take the other. A conditional gives a program this kind of choice.

## The mental model

> A condition is a question with a true or false answer. An if/else statement runs one branch for true and the other for false.

## The mechanism

`>=` asks whether the left value is greater than or equal to the right. `if` checks the expression inside parentheses. Braces enclose a group of instructions. `else` introduces the group used when the condition is false. Only one group runs in this example.

```javascript
const ticketCount = 3;
if (ticketCount >= 3) {
  console.log("Enter");
} else {
  console.log("Wait");
}
```

Three is equal to three, so the condition is true and Enter is displayed. Wait is not displayed. With two tickets, the condition is false and only Wait appears.

## Guided practice

Predict the output for ticketCount values 2, 3, and 4. Which of these reveals whether equality is included?

You can complete this exercise on paper or in your head, including offline. Predict first; then open the answer.

<details>

2 gives Wait; 3 gives Enter; 4 gives Enter. The value 3 checks equality at the cutoff.
