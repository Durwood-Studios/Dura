## Why this matters

A receipt can show the wrong total even when every line looks plausible. Naming values lets you reuse a number, but you must distinguish the name from the value it refers to.

## Start with something familiar

Imagine a coat-check ticket marked coatNumber. The label tells you where to look up a number; it is not the number itself. In code, a variable is a name associated with a value.

## The mental model

> A variable name refers to a value. Quoted text represents its own characters, even when it spells the same word as a variable.

## The mechanism

`const` introduces a name that cannot be reassigned. `=` gives it its initial value. A number such as `3` can participate in arithmetic; quoted text such as `"3"` is a different kind of value. `+` adds the numbers in this example. Read the right side of `=` before recording the value for the name on the left.

```javascript
const ticketCount = 3;
const extraTickets = 2;
console.log(ticketCount + extraTickets);
console.log("ticketCount");
```

The first displayed value is 5. The second is the text ticketCount. The second instruction uses quotation marks, so JavaScript does not look up the named value.
