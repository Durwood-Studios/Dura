## Why this matters

Code can calculate the right answer yet display nothing. Understanding the difference between returning and displaying a result helps you diagnose that apparent contradiction.

## Start with something familiar

Imagine a counter that takes an empty cup and hands back a filled cup. The counter has an input and a result; announcing the result is a separate action. A function is a named group of instructions you can call with inputs.

## The mental model

> A function call supplies values to named parameters. Return sends a result back to the caller; console.log displays a value.

## The mechanism

`function` defines the operation. The name `addDelivery` identifies it. The name inside parentheses, `itemCost`, is a parameter: a name for the input during a call. `return` sends the computed value back. Calling `addDelivery(8)` supplies the number eight. The returned result can be stored under another name.

```javascript
function addDelivery(itemCost) {
  return itemCost + 2;
}
const totalCost = addDelivery(8);
console.log(totalCost);
```

The call supplies 8, the function returns 10, totalCost refers to 10, and the final instruction displays 10. Defining the function alone does not call it.
