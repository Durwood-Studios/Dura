## Why this matters

Your computer has two completely different kinds of memory, and they behave nothing alike. One is fast and forgets everything when you unplug it. The other normally retains saved data without power, although devices can fail. Almost every performance question — "why is this app slow?" — comes back to this distinction.

## Start with something familiar

Picture ingredients in a fridge and ingredients on a kitchen counter. The counter is the active work area; the fridge keeps supplies between meals.

## The mental model

> RAM holds active working data; storage retains saved data without power. An address identifies a memory location.

## RAM: the workbench

RAM is where running programs live _right now_. When you open a saved file, data is loaded from storage into RAM for the program to use. RAM is fast — billions of operations per second — but it's volatile. Pull the plug and it's gone.

Think of it like a kitchen counter. The food in the fridge is your storage. The food on the counter is in RAM, ready to chop, mix, and cook.

## Storage: the fridge

A solid-state drive or hard drive is _persistent_. The file you saved this morning will still be there next week. Storage usually has more capacity and higher access latency than RAM.

This is why opening a huge document takes time, and why scrolling through it later feels instant: the slow part was loading it into RAM.

## Addresses

Every byte in RAM has a numeric address, like a house on a street. When you write a number into memory, the processor (CPU) isn't asked "remember this number for me" — it's asked "put this number at address 0x7fff5fbff8a0."

You won't usually deal with addresses directly. A memory-access error can occur when a program tries to read or write an address it is not allowed to use.

## Guided practice

A document has an unsaved edit when power fails. Which copy can remain: the saved file or the unsaved working copy?

Predict on paper or in your head before opening the answer; no installation or internet connection is needed.

<details>
  <summary>Reveal the practice answer</summary>

The saved file can remain in storage. The unsaved working copy in ordinary RAM is lost; autosave may have separately saved a newer copy.

</details>
