## Why this matters

Delay loops and SysTick let you count milliseconds. But real embedded work requires more: a motor controller needs 20 kHz PWM with microsecond-precise dead time between complementary switches; a servo controller needs to measure 1-2 ms pulse widths on an RC receiver with microsecond resolution; a sonar needs a 10 µs transmit pulse followed by a capture window starting at a specific count. General-purpose timers on Cortex-M can do all of this in hardware, with interrupt overhead only at the event — not per clock cycle.

## PSC and ARR: frequency and resolution

Every timer has two parameters that set its operating point:

- **PSC (Prescaler)** — divides the input clock: timer clock = input clock / (PSC + 1)
- **ARR (Auto-Reload Register)** — sets the period: the counter counts from 0 to ARR, then reloads

Timer period = (PSC + 1) × (ARR + 1) / input_clock_Hz

For TIM1 on STM32F4 (APB2 timer clock = 168 MHz) at 20 kHz PWM with 12-bit resolution (4096 steps):

```
Period = 1/20000 Hz = 50 µs
ARR = 4095 (12-bit range: 0-4095)
(PSC + 1) × 4096 / 168,000,000 = 50 µs
(PSC + 1) = 50e-6 × 168e6 / 4096 ≈ 2.05 → round to 2
Actual PSC = 1
Actual period = 2 × 4096 / 168,000,000 = 48.76 µs → 20.5 kHz
```

Close enough for most motor control. Fine-tune by adjusting ARR or PSC.

## PWM generation with TIM1 — complementary outputs

TIM1 is the STM32F4 "advanced control timer" — it has complementary output pairs (OCn and OCnN) with programmable dead time, essential for H-bridge motor control where both switches must never be on simultaneously.

```c
#include <stdint.h>

/* TIM1 base 0x40010000, on APB2 */
#define TIM1_BASE  0x40010000UL
#define TIM1_CR1   (*(volatile uint32_t *)(TIM1_BASE + 0x00))
#define TIM1_BDTR  (*(volatile uint32_t *)(TIM1_BASE + 0x44))  /* Break and dead-time */
#define TIM1_CCER  (*(volatile uint32_t *)(TIM1_BASE + 0x20))  /* Capture/compare enable */
#define TIM1_CCMR1 (*(volatile uint32_t *)(TIM1_BASE + 0x18))  /* CC mode register 1 */
#define TIM1_PSC   (*(volatile uint32_t *)(TIM1_BASE + 0x28))
#define TIM1_ARR   (*(volatile uint32_t *)(TIM1_BASE + 0x2C))
#define TIM1_CCR1  (*(volatile uint32_t *)(TIM1_BASE + 0x34))  /* Ch1 compare value */
#define TIM1_EGR   (*(volatile uint32_t *)(TIM1_BASE + 0x14))

void tim1_pwm_init(void) {
    /* Enable TIM1 clock on APB2 */
    *(volatile uint32_t *)(0x40023800UL + 0x44) |= (1U << 0);

    /* GPIO: PA8 = TIM1_CH1 (AF1), PA7 = TIM1_CH1N (AF1) — actual pins chip-specific */
    /* (GPIO setup omitted for brevity — same pattern as E2 lessons) */

    /* Stop timer before configuration */
    TIM1_CR1 = 0;

    /* PSC and ARR for ~20 kHz with 4095 steps */
    TIM1_PSC = 1U;         /* Divides 168 MHz by 2 = 84 MHz timer clock */
    TIM1_ARR = 4095U;      /* Period: 4096 counts = 48.76 µs ≈ 20.5 kHz */

    /* Center-aligned mode (CMS=01): counter counts up then down.
       This doubles the effective period but produces symmetric PWM suitable
       for three-phase motor control. For simple PWM, use edge-aligned (CMS=00). */
    TIM1_CR1 = (0b01U << 5);   /* CMS = 01: center-aligned mode 1 */

    /* CH1: PWM mode 1 (OC1M = 110), preload enable (OC1PE = 1) */
    TIM1_CCMR1 = (0b110U << 4) | (1U << 3);

    /* Enable CH1 (CC1E) and CH1N complementary (CC1NE) outputs */
    TIM1_CCER = (1U << 0) | (1U << 2);   /* CC1E | CC1NE */

    /* Dead time: DTG[7:0] in BDTR. For DTG < 128: dead_time = DTG × t_DTS
       t_DTS = 1 / (168 MHz / 2) ≈ 11.9 ns. For 500 ns dead time:
       DTG = 500 ns / 11.9 ns ≈ 42 */
    TIM1_BDTR = (1U << 15) |   /* MOE: main output enable */
                42U;            /* DTG: dead time ≈ 500 ns */

    /* Initial duty: 50% = CCR1 / ARR = 2048 / 4096 */
    TIM1_CCR1 = 2048U;

    /* Generate update event to load PSC/ARR/BDTR into shadow registers */
    TIM1_EGR = (1U << 0);

    /* Enable timer */
    TIM1_CR1 |= (1U << 0);    /* CEN */
}

/* Change duty cycle at any time — new value loads on next update event */
void pwm_set_duty(uint32_t duty_0_to_4095) {
    TIM1_CCR1 = duty_0_to_4095;   /* Write is buffered in shadow register */
}
```

The `OC1PE` bit (preload enable) makes CCR1 writes buffered: the new duty cycle takes effect at the next timer update event, not immediately mid-cycle. Without preload, writing CCR1 while the counter is running can produce a glitch where the current cycle is truncated.

## Input capture — measuring external pulse width

TIM2 in input-capture mode measures the time between two external edges. The capture/compare register (CCR) latches the current counter value on each edge.

Measuring the period of a 50 Hz (20 ms) RC receiver pulse on PA0 (TIM2_CH1):

```c
#define TIM2_BASE  0x40000000UL
#define TIM2_CR1   (*(volatile uint32_t *)(TIM2_BASE + 0x00))
#define TIM2_SMCR  (*(volatile uint32_t *)(TIM2_BASE + 0x08))
#define TIM2_CCMR1 (*(volatile uint32_t *)(TIM2_BASE + 0x18))
#define TIM2_CCER  (*(volatile uint32_t *)(TIM2_BASE + 0x20))
#define TIM2_PSC   (*(volatile uint32_t *)(TIM2_BASE + 0x28))
#define TIM2_ARR   (*(volatile uint32_t *)(TIM2_BASE + 0x2C))
#define TIM2_CCR1  (*(volatile uint32_t *)(TIM2_BASE + 0x34))
#define TIM2_DIER  (*(volatile uint32_t *)(TIM2_BASE + 0x0C))
#define TIM2_SR    (*(volatile uint32_t *)(TIM2_BASE + 0x10))

static volatile uint32_t last_capture = 0U;
static volatile uint32_t pulse_width_us = 0U;

void tim2_input_capture_init(void) {
    /* APB1 timer clock = 84 MHz */
    *(volatile uint32_t *)(0x40023800UL + 0x40) |= (1U << 0);  /* TIM2EN */

    /* PA0 → TIM2_CH1 (AF1) — GPIO setup omitted */

    TIM2_PSC  = 84U - 1U;    /* 84 MHz / 84 = 1 MHz → 1 µs per count */
    TIM2_ARR  = 0xFFFFFFFFU; /* 32-bit counter, wrap at maximum */

    /* CH1 in input capture mode (CC1S = 01: map to TI1 = PA0) */
    TIM2_CCMR1 = (0b01U << 0);   /* CC1S = 01: input mapped to TI1 */

    /* Capture on rising edge (CC1P=0, CC1NP=0) */
    TIM2_CCER = (1U << 0);        /* CC1E: enable capture */

    /* Enable capture interrupt */
    TIM2_DIER = (1U << 1);        /* CC1IE */

    NVIC_SetPriority(TIM2_IRQn, 6U);
    NVIC_EnableIRQ(TIM2_IRQn);

    TIM2_CR1 = (1U << 0);         /* CEN: start */
}

void TIM2_IRQHandler(void) {
    if (TIM2_SR & (1U << 1)) {    /* CC1IF: capture event */
        TIM2_SR &= ~(1U << 1);

        uint32_t captured = TIM2_CCR1;   /* Reading CCR1 clears CC1IF too */

        /* First capture: record timestamp; second: compute difference */
        if (last_capture == 0U) {
            last_capture = captured;
        } else {
            pulse_width_us = captured - last_capture;
            last_capture = captured;
        }
    }
}
```

For a 50 Hz input, `pulse_width_us` gives the period in microseconds. For pulse-width measurement (servo: 1000-2000 µs HIGH), reconfigure to capture rising edge, record timestamp, configure to capture falling edge, compute the HIGH duration.

## Output compare — precise one-shot timing

Output-compare mode fires an interrupt when the counter reaches CCR, without affecting the GPIO pin:

```c
/* Generate an interrupt exactly 500 µs after calling this function */
void tim2_oc_oneshot(uint32_t delay_us) {
    /* TIM2 runs at 1 MHz from the input-capture setup above */
    uint32_t target = TIM2_CNT + delay_us;

    /* CH2 output compare (CC2S = 00 = output), no waveform (OC2M = 000) */
    TIM2_CCMR1 &= ~((0b11U << 8) | (0b111U << 12));
    TIM2_CCR2   = target;
    TIM2_DIER  |= (1U << 2);   /* CC2IE */
    TIM2_CCER  |= (1U << 4);   /* CC2E */
    TIM2_SR    &= ~(1U << 2);  /* Clear any pending CC2IF */
}

void TIM2_IRQHandler(void) {
    if (TIM2_SR & (1U << 2)) { /* CC2IF */
        TIM2_SR   &= ~(1U << 2);
        TIM2_DIER &= ~(1U << 2);   /* One-shot: disable after firing */
        TIM2_CCER &= ~(1U << 4);
        /* Execute the timed action */
        do_timed_action();
    }
    /* ... handle CC1IF for input capture above ... */
}
```

Output compare is used for single-shot delays without busy-waiting, for generating precisely timed pulses on multiple pins, and in RTIC (Lesson E6) for scheduling async tasks at specific instants.
