## Why this matters

SPI (Serial Peripheral Interface) is to embedded systems what TCP is to networking: not glamorous, but everything depends on it. The W25Q128 flash chip in your board, the LSM6DSO IMU in every phone, the ILI9341 display controller on cheap TFT panels — they all speak SPI. Unlike UART, SPI is synchronous: the master provides the clock, and bit timing is exact. Unlike I2C, SPI is full-duplex: bytes go both directions simultaneously. The result is a bus that's fast (10s of MHz), simple (four wires), and widely supported — and where the most common bug is a two-bit configuration mistake that produces a completely dead bus.

## SPI fundamentals

SPI has four signals:

- **SCK** (Serial Clock) — generated by the master; drives bit timing on both sides.
- **MOSI** (Master Out, Slave In) — data from master to slave.
- **MISO** (Master In, Slave Out) — data from slave to master.
- **CS** (Chip Select, active low) — selects which slave participates.

The master asserts CS (drives it LOW), clocks out bytes on MOSI while simultaneously reading bytes on MISO, then deasserts CS (drives it HIGH). There is no addressing — CS-selection is purely GPIO-based. Multiple slaves share SCK, MOSI, MISO but each has its own CS pin.

### Clock mode: CPOL and CPHA

The two SPI clock configuration bits determine when data is latched and when it changes:

| Mode | CPOL | CPHA | Idle clock | Sample edge |
| ---- | ---- | ---- | ---------- | ----------- |
| 0    | 0    | 0    | LOW        | Rising      |
| 1    | 0    | 1    | LOW        | Falling     |
| 2    | 1    | 0    | HIGH       | Falling     |
| 3    | 1    | 1    | HIGH       | Rising      |

The slave's datasheet specifies which mode it requires — always look for "SPI Mode" or a timing diagram labeled "CPOL=X, CPHA=Y". Using the wrong mode produces a bus where bytes transfer without error flags, but the data is shifted by one bit or completely wrong.

## SPI1 registers on STM32F4 (RM0090)

SPI1 base address: `0x40013000`. Key registers:

| Register | Offset | Purpose                                           |
| -------- | ------ | ------------------------------------------------- |
| CR1      | 0x00   | Clock, mode, baud rate, frame format, enable      |
| CR2      | 0x04   | DMA, interrupt enables, SS output enable          |
| SR       | 0x08   | Status: TXE, RXNE, BSY, OVR flags                 |
| DR       | 0x0C   | Data register: write to transmit, read to receive |

```c
#include <stdint.h>

#define SPI1_BASE  0x40013000UL
#define SPI1_CR1   (*(volatile uint32_t *)(SPI1_BASE + 0x00))
#define SPI1_CR2   (*(volatile uint32_t *)(SPI1_BASE + 0x04))
#define SPI1_SR    (*(volatile uint32_t *)(SPI1_BASE + 0x08))
#define SPI1_DR    (*(volatile uint32_t *)(SPI1_BASE + 0x0C))

/* SR flags */
#define SPI_SR_TXE    (1U << 1)   /* TX buffer empty */
#define SPI_SR_RXNE   (1U << 0)   /* RX buffer not empty */
#define SPI_SR_BSY    (1U << 7)   /* Bus busy (transfer in progress) */

/* CR1 bits */
#define SPI_CR1_MSTR  (1U << 2)   /* Master mode */
#define SPI_CR1_SPE   (1U << 6)   /* SPI enable */
#define SPI_CR1_BR    (7U << 3)   /* Baud rate bits [5:3] */
```

## Initialization — clocks, pins, SPI peripheral

```c
/* Alternate function registers for GPIOA */
#define GPIOA_BASE    0x40020000UL
#define GPIOA_MODER   (*(volatile uint32_t *)(GPIOA_BASE + 0x00))
#define GPIOA_OSPEEDR (*(volatile uint32_t *)(GPIOA_BASE + 0x08))
#define GPIOA_AFRL    (*(volatile uint32_t *)(GPIOA_BASE + 0x20))

/* CS pin — PA4 as GPIO output (software CS, gives us full control of timing) */
#define GPIOA_ODR     (*(volatile uint32_t *)(GPIOA_BASE + 0x14))
#define GPIOA_BSRR    (*(volatile uint32_t *)(GPIOA_BASE + 0x18))
#define CS_PIN        4

static inline void cs_assert(void)   { GPIOA_BSRR = (1U << (CS_PIN + 16)); }
static inline void cs_deassert(void) { GPIOA_BSRR = (1U << CS_PIN); }

#define RCC_BASE       0x40023800UL
#define RCC_AHB1ENR   (*(volatile uint32_t *)(RCC_BASE + 0x30))
#define RCC_APB2ENR   (*(volatile uint32_t *)(RCC_BASE + 0x44))

void spi1_init(void) {
    /* 1. Enable clocks for GPIOA and SPI1 */
    RCC_AHB1ENR |= (1U << 0);   /* GPIOAEN */
    RCC_APB2ENR |= (1U << 12);  /* SPI1EN */

    /* 2. PA5=SCK, PA6=MISO, PA7=MOSI → Alternate Function 5 (SPI1) */
    /* MODER: bits 10-11=AF for PA5, 12-13=AF for PA6, 14-15=AF for PA7 */
    GPIOA_MODER &= ~((0b11U << 10) | (0b11U << 12) | (0b11U << 14));
    GPIOA_MODER |=  ((0b10U << 10) | (0b10U << 12) | (0b10U << 14));
    /* AFRL: 4 bits per pin; PA5=bits[23:20], PA6=bits[27:24], PA7=bits[31:28]; AF5=0b0101 */
    GPIOA_AFRL &= ~((0xFU << 20) | (0xFU << 24) | (0xFU << 28));
    GPIOA_AFRL |=  ((5U  << 20) | (5U  << 24) | (5U  << 28));
    /* High speed for SCK */
    GPIOA_OSPEEDR |= (0b11U << 10);

    /* 3. PA4 as GPIO output for CS (software-controlled) */
    GPIOA_MODER &= ~(0b11U << 8);
    GPIOA_MODER |=  (0b01U << 8);  /* Output */
    cs_deassert();                  /* CS idle HIGH */

    /* 4. Configure SPI1:
       MSTR = 1 (master), SPE not yet (enable last),
       BR[2:0] = 0b010 = fPCLK/8 (APB2 84 MHz → ~10.5 MHz SPI clock),
       CPOL = 0, CPHA = 0 (Mode 0 — adjust for your slave's datasheet),
       DFF = 0 (8-bit frames), SSM = 1, SSI = 1 (software SS management) */
    SPI1_CR1 = (0b010U << 3) |  /* BR: /8 */
               SPI_CR1_MSTR  |
               (1U << 9)     |  /* SSM: software slave management */
               (1U << 8);      /* SSI: internal slave select */
    /* Enable */
    SPI1_CR1 |= SPI_CR1_SPE;
}
```

## Polled full-duplex transfer

SPI is inherently full-duplex — every byte you transmit produces a received byte simultaneously. The `spi_xfer` function sends one byte and returns what was received at the same time:

```c
uint8_t spi_xfer(uint8_t tx_byte) {
    /* Wait for TX buffer to be empty */
    while (!(SPI1_SR & SPI_SR_TXE)) { }
    SPI1_DR = tx_byte;

    /* Wait for received byte to be available */
    while (!(SPI1_SR & SPI_SR_RXNE)) { }
    return (uint8_t)SPI1_DR;
}
```

Reading a register from a device that uses an address byte followed by a data byte (most SPI sensors):

```c
uint8_t spi_read_register(uint8_t reg_addr) {
    cs_assert();

    /* Send register address with read bit (device-specific — many use bit 7 = 1 for read) */
    spi_xfer(reg_addr | 0x80U);

    /* Send dummy byte to clock in the response */
    uint8_t result = spi_xfer(0xFFU);

    /* Wait for bus to idle before releasing CS — BSY must be clear */
    while (SPI1_SR & SPI_SR_BSY) { }
    cs_deassert();

    return result;
}

void spi_write_register(uint8_t reg_addr, uint8_t value) {
    cs_assert();
    spi_xfer(reg_addr & 0x7FU);  /* Write bit = 0 */
    spi_xfer(value);
    while (SPI1_SR & SPI_SR_BSY) { }
    cs_deassert();
}
```

The BSY wait before CS deassert is critical. STM32F4's SPI peripheral sets BSY while a transfer is in progress. If you release CS while BSY is set, the last clock edges may not have completed and the slave's shift register is left in an undefined state — corrupting the next transfer.

## DMA-driven block transfer

For large transfers (display frame buffers, flash writes), DMA eliminates the per-byte ISR overhead:

```c
void spi1_dma_send(const uint8_t *data, uint16_t len) {
    /* DMA2 Stream 3 Channel 3 = SPI1 TX on STM32F4 */
    #define DMA2_BASE     0x40026400UL
    #define DMA2_S3CR     (*(volatile uint32_t *)(DMA2_BASE + 0x58))
    #define DMA2_S3NDTR   (*(volatile uint32_t *)(DMA2_BASE + 0x5C))
    #define DMA2_S3PAR    (*(volatile uint32_t *)(DMA2_BASE + 0x60))
    #define DMA2_S3M0AR   (*(volatile uint32_t *)(DMA2_BASE + 0x64))

    /* Disable stream, wait for it to clear */
    DMA2_S3CR = 0;
    while (DMA2_S3CR & 1U) { }

    DMA2_S3PAR  = (uint32_t)&SPI1_DR;       /* Destination: SPI1 data register */
    DMA2_S3M0AR = (uint32_t)data;            /* Source: caller's buffer */
    DMA2_S3NDTR = len;
    DMA2_S3CR =
        (3U << 25) |   /* Channel 3 */
        (1U << 10) |   /* MINC: memory address increments */
        (1U << 6);     /* DIR: memory to peripheral */

    SPI1_CR2 |= (1U << 1);    /* TXDMAEN: enable DMA for TX */
    DMA2_S3CR |= 1U;           /* Enable stream */

    /* Wait for transfer complete — or use TCIE interrupt */
    while (!(DMA2_S3CR & (1U << 4))) { }   /* TCIE pending */
    while (SPI1_SR & SPI_SR_BSY) { }       /* Wait for last byte out */

    SPI1_CR2 &= ~(1U << 1);   /* Disable DMA */
}
```

For a 320×240 pixel display, a DMA-driven full frame buffer transfer takes ~37 ms at 10.5 MHz SPI without the CPU touching each byte. The CPU is free to do UI work during the transfer.

## CPOL/CPHA mismatch — the silent failure

If you configure the wrong SPI mode, the bus transfers appear to complete (TXE and RXNE cycle correctly) but the data is garbage. No error flag fires. This is the most common SPI debugging trap.

Diagnostic procedure:

1. Check the slave's datasheet timing diagram. Find the SPI mode number (0–3) or the CPOL/CPHA values explicitly.
2. Verify SCK idle state with a logic analyzer or oscilloscope: Mode 0/1 has SCK idle LOW; Mode 2/3 has SCK idle HIGH.
3. Check the sample edge: Mode 0/2 samples on the first clock edge; Mode 1/3 samples on the second.
4. Update CR1 CPOL and CPHA bits to match.
