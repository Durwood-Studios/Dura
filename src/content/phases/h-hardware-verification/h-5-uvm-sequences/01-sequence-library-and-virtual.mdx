## A minimal sequence

```systemverilog
class write_seq extends uvm_sequence #(write_txn);
    `uvm_object_utils(write_seq)
    rand int n;
    constraint c_n { n inside { [10:100] }; }

    function new(string name = "write_seq");
        super.new(name);
    endfunction

    task body();
        write_txn tx;
        repeat (n) begin
            tx = write_txn::type_id::create("tx");
            start_item(tx);
            assert(tx.randomize());
            finish_item(tx);
        end
    endtask
endclass
```

`start_item` / `finish_item` is the handshake with the sequencer:

- `start_item` requests permission to send (sequencer may block if another sequence has priority).
- Between, the transaction is randomized and modified as needed.
- `finish_item` hands the transaction to the driver and waits for ack.

## Running sequences

In the test:

```systemverilog
class basic_test extends uvm_test;
    `uvm_component_utils(basic_test)
    my_env env;

    function void build_phase(uvm_phase phase);
        env = my_env::type_id::create("env", this);
    endfunction

    task run_phase(uvm_phase phase);
        write_seq seq = write_seq::type_id::create("seq");
        phase.raise_objection(this);
        seq.start(env.agent.sequencer);
        phase.drop_objection(this);
    endtask
endclass
```

Objections tell the UVM phase scheduler the run_phase is not done. When the last objection drops, the phase ends. Without objections, the test ends immediately at time 0.

## Layered sequences

A common pattern: one sequence calls another.

```systemverilog
class burst_then_idle_seq extends uvm_sequence #(write_txn);
    `uvm_object_utils(burst_then_idle_seq)

    task body();
        write_seq    burst = write_seq::type_id::create("burst");
        idle_seq     idle  = idle_seq::type_id::create("idle");
        burst.start(m_sequencer, this);   // child sequence
        idle.start(m_sequencer, this);
    endtask
endclass
```

Child sequences inherit the parent's sequencer, so the same sequencer drives everything.

## Virtual sequences — coordinating multiple agents

A virtual sequence runs at a higher level than any individual agent. It coordinates sequences across agents:

```systemverilog
class scenario_seq extends uvm_sequence;
    `uvm_object_utils(scenario_seq)

    // Handles to multiple sequencers, set by the test
    axi_sequencer  axi_seq;
    apb_sequencer  apb_seq;
    irq_sequencer  irq_seq;

    task body();
        // Programmatic coordination of three agents
        fork
            begin
                axi_write_seq w = axi_write_seq::type_id::create("w");
                w.start(axi_seq);
            end
            begin
                #1000ns;   // 1 us delay
                apb_config_seq c = apb_config_seq::type_id::create("c");
                c.start(apb_seq);
            end
            begin
                wait_for_irq_seq i = wait_for_irq_seq::type_id::create("i");
                i.start(irq_seq);
            end
        join_all
    endtask
endclass
```

The virtual sequencer has handles to all the sub-sequencers it orchestrates. The virtual sequence body() composes lower-level sequences across them, with full SV concurrency control.

This is how you model complex system scenarios: "configure registers via APB, then drive AXI traffic, then wait for an interrupt — all coordinated in time."

## Sequence library

A regression test typically runs MANY sequences in MANY combinations. A sequence library object packages the menu:

```systemverilog
class my_seq_lib extends uvm_sequence_library #(write_txn);
    `uvm_object_utils(my_seq_lib)
    function new(string name = "my_seq_lib");
        super.new(name);
        init_sequence_library();
    endfunction
endclass

// Register sequences in the library
write_seq::type_id::set_type_override(write_seq::get_type());
my_seq_lib::add_typewide_sequence(write_seq::get_type());
my_seq_lib::add_typewide_sequence(error_inject_seq::get_type());
```

The library can run sequences in user-controlled random order with weights. Coverage feedback then refines which sequences run more or less.
