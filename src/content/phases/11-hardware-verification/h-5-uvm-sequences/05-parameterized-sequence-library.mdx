## The reuse problem

Test-first DV teams end up with hundreds of files named `test_write_aligned.sv`, `test_write_unaligned.sv`, `test_write_boundary.sv`. Each differs by three field assignments. Any protocol change requires updating each file separately.

Parameterized sequences solve this by encoding the variation as fields:

```systemverilog
class write_seq extends uvm_sequence #(axi_txn);
    `uvm_object_utils(write_seq)

    // Configurable parameters — set these before calling start()
    rand int unsigned num_txns;
    rand bit          force_aligned;   // true: aligned only; false: random
    rand bit [31:0]   base_addr;
    rand bit [31:0]   addr_mask;

    constraint c_n      { num_txns inside { [10:200] }; }
    constraint c_base   { (base_addr & addr_mask) == base_addr; }

    task body();
        axi_txn tx;
        repeat (num_txns) begin
            tx = axi_txn::type_id::create("tx");
            start_item(tx);
            if (force_aligned)
                assert(tx.randomize() with { addr[1:0] == 2'b00; });
            else
                assert(tx.randomize());
            finish_item(tx);
        end
    endtask
endclass
```

In each test, change only the sequence parameters:

```systemverilog
// Aligned write test
write_seq s = write_seq::type_id::create("s");
s.force_aligned = 1;
s.base_addr     = 32'h0;
s.num_txns      = 100;
s.start(sequencer);

// Boundary test — same class, different params
write_seq s2 = write_seq::type_id::create("s2");
s2.force_aligned = 0;
s2.base_addr     = 32'hFFFF_0000;
s2.num_txns      = 50;
s2.start(sequencer);
```

## Configuring sequences via config_db

For sequences buried deep in a virtual sequence hierarchy, passing parameters through constructor chains is unwieldy. Use `uvm_config_db` instead:

```systemverilog
class write_seq extends uvm_sequence #(axi_txn);
    `uvm_object_utils(write_seq)
    int unsigned num_txns = 100;   // default
    bit          force_aligned = 0;

    function void pre_start();
        // Fetch config from the DB; use the default if not set
        void'(uvm_config_db #(int unsigned)::get(
            m_sequencer, get_full_name(), "num_txns", num_txns));
        void'(uvm_config_db #(bit)::get(
            m_sequencer, get_full_name(), "force_aligned", force_aligned));
    endfunction

    task body();
        // ... body uses num_txns and force_aligned
    endtask
endclass

// In the test, set before start:
uvm_config_db #(int unsigned)::set(null, "*.write_seq*", "num_txns", 500);
uvm_config_db #(bit)::set(null, "*.write_seq*", "force_aligned", 1'b1);
```

The wildcard path `"*.write_seq*"` targets any write_seq instance created anywhere in the testbench hierarchy. The sequence retrieves its config in `pre_start()`, before `body()` runs.

## UVM sequence library — weighted random selection

A sequence library automatically selects and runs sequences from a registered set, with configurable weights and modes:

```systemverilog
// Define a sequence library type
class axi_seq_lib extends uvm_sequence_library #(axi_txn);
    `uvm_object_utils(axi_seq_lib)
    `uvm_sequence_library_utils(axi_seq_lib)

    function new(string name = "axi_seq_lib");
        super.new(name);
        init_sequence_library();
    endfunction
endclass

// Register sequences into the library (in a package or test)
initial begin
    axi_seq_lib::add_typewide_sequence(write_seq::get_type());
    axi_seq_lib::add_typewide_sequence(read_seq::get_type());
    axi_seq_lib::add_typewide_sequence(burst_seq::get_type());
    axi_seq_lib::add_typewide_sequence(error_seq::get_type());
end
```

The library's `min_random_count` and `max_random_count` set how many sequences to run. Mode options:

```systemverilog
// Configure the library in the test
uvm_config_db #(uvm_sequence_lib_mode)::set(
    null, "*.axi_seqr.main_phase", "default_sequence.selection_mode",
    UVM_SEQ_LIB_RAND);       // or FIFO, ITEM, USER
uvm_config_db #(int)::set(
    null, "*.axi_seqr.main_phase", "default_sequence.min_random_count", 10);
uvm_config_db #(int)::set(
    null, "*.axi_seqr.main_phase", "default_sequence.max_random_count", 50);
```

Modes:

- `UVM_SEQ_LIB_RAND`: randomly selects among registered sequences
- `UVM_SEQ_LIB_FIFO`: runs each registered sequence once in order
- `UVM_SEQ_LIB_ITEM`: runs a single sequence item (the simplest form)

## Coverage-driven sequence selection

Link coverage to sequence selection by checking coverage in the sequence body:

```systemverilog
class coverage_aware_seq extends uvm_sequence #(axi_txn);
    `uvm_object_utils(coverage_aware_seq)

    // Reference to coverage model (set before start)
    axi_coverage cov_model;

    task body();
        axi_txn tx;
        int idle_attempts = 0;

        // Drive stimulus until coverage closes or we've tried enough
        while (cov_model.get_coverage() < 99.0 && idle_attempts < 1000) begin
            tx = axi_txn::type_id::create("tx");
            start_item(tx);

            // Bias constraints toward coverage holes
            if (!cov_model.is_covered(AXI_WRAP_BURST))
                assert(tx.randomize() with { burst_type == AXI_WRAP; });
            else if (!cov_model.is_covered(AXI_NARROW))
                assert(tx.randomize() with { size < 3; });
            else
                assert(tx.randomize());

            finish_item(tx);

            // Count attempts without coverage improvement
            if (cov_model.get_coverage() < 99.0)
                idle_attempts++;
            else
                idle_attempts = 0;
        end

        if (cov_model.get_coverage() < 99.0)
            `uvm_warning("CVG", $sformatf("Coverage closed at %.1f%%",
                cov_model.get_coverage()))
    endtask
endclass
```

This closes the constrained-random verification loop inside a single sequence: measure, bias, repeat.

## Building the complete regression library

```
sequence_library/
├── axi_seq_lib.sv           ← registers all sequences, configures modes
├── axi_write_seq.sv         ← parameterized write: aligned, unaligned, burst
├── axi_read_seq.sv          ← parameterized read: sequential, random, strided
├── axi_error_seq.sv         ← protocol violations for error handling coverage
├── axi_back_to_back_seq.sv  ← B2B transactions for timing coverage
└── axi_mixed_seq.sv         ← read and write interleaved
```

Each test imports the library package and calls one of:

- `seq_lib.start(seqr)` — runs the full library in configured mode
- `specific_seq.start(seqr)` — runs a targeted scenario

Coverage closure uses the library; directed testing uses individual sequences. The same code serves both flows.
