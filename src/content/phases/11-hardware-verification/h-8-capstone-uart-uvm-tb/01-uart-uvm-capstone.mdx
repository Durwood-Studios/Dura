## The capstone target

You will verify a UART IP block (any open-source UART RTL — OpenCores has several). Your testbench:

1. SystemVerilog interface for the UART pins (TX, RX, RTS, CTS, clk, rst_n).
2. UVM agent for the parallel side (driver, monitor, sequencer).
3. UVM agent for the serial side (passive monitor + reference model).
4. Scoreboard checking parallel-in equals serial-out (after framing) and vice versa.
5. Constrained-random sequence library covering baud rates, parity modes, frame lengths.
6. Functional coverage model on baud-rate × parity × frame-error × overrun-error.
7. At least 3 SVA assertions on protocol invariants.
8. Test that achieves 100% coverage closure.

The grading rubric matches what an experienced DV reviewer applies to a portfolio submission.

## The architecture

```
                    ┌──────────────┐
                    │   uvm_test   │
                    └──────┬───────┘
                           │
                    ┌──────▼───────┐
                    │   uvm_env    │
                    └──┬───────┬───┘
                       │       │
        ┌──────────────▼─┐   ┌─▼────────────┐
        │ parallel_agent │   │ serial_agent │
        │  - driver      │   │  - monitor   │
        │  - monitor     │   │   (passive)  │
        │  - sequencer   │   └──────┬───────┘
        └──────┬─────────┘          │
               │                    │
               └──────► uart_scoreboard ◄──┘
```

The parallel agent drives the host-side bus (writes bytes to the UART's transmit register, reads from the receive register). The serial agent passively observes the UART's serial-out pin and reconstructs bytes from the bit stream. The scoreboard verifies that parallel-write bytes appear correctly on serial-out, and serial-in bit sequences appear correctly on parallel-read.

## Skeleton

```systemverilog
// uart_if.sv
interface uart_if(input logic clk, input logic rst_n);
    logic       tx, rx;
    logic       rts, cts;
    logic [7:0] tx_data, rx_data;
    logic       tx_valid, tx_ready;
    logic       rx_valid, rx_ready;
    logic [3:0] cfg_baud_div;
    logic [1:0] cfg_parity;
    modport dut    (input tx_data, tx_valid, cfg_baud_div, cfg_parity,
                    output tx_ready, rx_data, rx_valid);
    modport master (input tx_ready, rx_data, rx_valid,
                    output tx_data, tx_valid, cfg_baud_div, cfg_parity, rx_ready);
endinterface

// uart_txn.sv
class uart_txn extends uvm_sequence_item;
    `uvm_object_utils(uart_txn)
    rand bit [7:0] data;
    rand bit [3:0] baud_div;
    rand bit [1:0] parity;
    constraint c_baud { baud_div inside { 4'd1, 4'd2, 4'd4, 4'd8 }; }
    function new(string name = "uart_txn");
        super.new(name);
    endfunction
endclass

// uart_driver, uart_monitor, uart_agent, uart_scoreboard
// follow the H2 patterns

// uart_coverage.sv
class uart_cov extends uvm_subscriber #(uart_txn);
    `uvm_component_utils(uart_cov)
    uart_txn cur;
    covergroup cg;
        baud  : coverpoint cur.baud_div;
        par   : coverpoint cur.parity;
        cx    : cross baud, par;
    endgroup
    function new(string n, uvm_component p);
        super.new(n, p); cg = new();
    endfunction
    function void write(uart_txn t);
        cur = t; cg.sample();
    endfunction
endclass

// assertions in the DUT module or a bound module
module uart_assertions(uart_if vif);
    property p_tx_handshake;
        @(posedge vif.clk) disable iff (!vif.rst_n)
            vif.tx_valid && vif.tx_ready |=> ##[1:1000] !vif.tx_valid;
    endproperty
    assert property (p_tx_handshake);
endmodule
bind uart_dut uart_assertions u_assert(.*);
```

## Deliverables

The /verify-anchored submission includes:

1. **Source code** — all SV files, the DUT RTL or its license info, Makefile.
2. **README** — how to build (free Verilator path; commercial sim path), expected output.
3. **Coverage report** — final report showing 100% closure on your coverage model.
4. **Architecture diagram** — like the one above, annotated.
5. **Demo recording** — terminal output showing simulation + coverage closure.
6. **Hash anchor** — SHA-256 of the bundle; /verify certificate appended as Appendix V.

## Grading rubric

| Element            | Acceptable                                                | Incomplete                  |
| ------------------ | --------------------------------------------------------- | --------------------------- |
| Working sim        | Compiles + runs against a real UART RTL                   | Doesn't compile or simulate |
| UVM structure      | Agent + Sequencer + Driver + Monitor + Scoreboard present | Skips components            |
| Constrained-random | Sequences use rand fields + constraints                   | Hard-coded values           |
| Coverage closure   | 100% on documented coverage model                         | < 100% or no model          |
| Assertions         | At least 3 SVA properties on protocol invariants          | None or trivial             |
| Hash anchor        | /verify certificate in Appendix V                         | Missing                     |

## Submission

1. Bundle source + docs + coverage report.
2. Compute SHA-256.
3. Submit to /verify with title "Phase H Capstone — UART UVM Testbench".
4. Append certificate as Appendix V.
5. Publish.
