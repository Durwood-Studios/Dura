## Why this matters

After a week of random simulation, your coverage report says 98%. The team celebrates. But two questions are unanswered:

1. Does "covered" mean the bin was hit once — or enough times to build statistical confidence in the DUT's behavior?
2. Does the 98% aggregate hide a specific agent or instance that never exercised certain bins?

Covergroup options answer both questions. They turn a binary "hit or not" model into a richer "hit enough times, weighted by importance, tracked per instance" model.

## option.at_least — minimum hit count

By default, a bin is covered after a single hit. For many protocol scenarios, one observation isn't enough:

```systemverilog
covergroup cg_axi_burst;
    option.at_least = 10;   // Each bin must be hit at least 10 times

    cp_len : coverpoint len {
        bins single = { 1 };
        bins short  = { [2:8] };
        bins medium = { [9:64] };
        bins long   = { [65:256] };
    }
endgroup
```

With `at_least = 10`, the 98% report now means each bin has been hit 10+ times. The statistical confidence in the DUT behavior across those scenarios is much higher.

Set `at_least` per-covergroup globally, or per-bin individually:

```systemverilog
covergroup cg_mixed;
    cp_type : coverpoint txn_type {
        bins read   = { 0 } iff (at_least == 20);   // Reads need 20 hits
        bins write  = { 1 } iff (at_least == 50);   // Writes need 50 (more important)
        bins atomic = { 2 };                         // Uses group default
    }
    option.at_least = 5;   // Group default: 5 hits
endgroup
```

## option.weight — coverage contribution

Not all coverpoints are equally important. `weight` controls how much a coverpoint contributes to the group's aggregate coverage percentage:

```systemverilog
covergroup cg_protocol;
    option.weight = 1;   // Group-level default

    // This cross is the most important thing — 3x weight
    cx_addr_type : cross cp_addr, cp_txn_type {
        option.weight = 3;
    }

    // Address alone matters less than the cross
    cp_addr : coverpoint addr {
        option.weight = 1;
    }

    // Transaction type alone is least important (the cross covers it)
    cp_txn_type : coverpoint txn_type {
        option.weight = 1;
    }
endgroup
```

Aggregate formula: `total_weight_covered / total_weight`. If the cross (weight=3) is 100% covered and both coverpoints (weight=1 each) are 80%, the aggregate is `(3×100 + 1×80 + 1×80) / (3+1+1) = 92%`.

A cross at weight 0 appears in the report but doesn't affect the aggregate — useful for informational tracking without changing the sign-off number.

## option.goal — per-coverpoint completion target

The `goal` option sets the coverage percentage that represents "done" for a coverpoint. Default is 100%.

```systemverilog
covergroup cg_with_goals;
    // This coverpoint only needs 90% — some bins are legitimately hard to reach
    cp_addr : coverpoint addr {
        option.goal = 90;
    }

    // This cross needs all bins — no excuses
    cx_primary : cross cp_addr, cp_size {
        option.goal = 100;
    }
endgroup
```

`goal` is distinct from `at_least`: `goal` is the percentage of bins that must be covered; `at_least` is how many hits each covered bin needs. Use `goal` when some bins will legitimately not be covered (e.g., hardware-impossible combinations) and you don't want to use `ignore_bins` (which removes bins from the report entirely).

## type_option.merge_instances — per-instance vs merged

The most impactful option for UVM testbenches is `per_instance`. By default, all instances of a covergroup class merge their data — you see the aggregate. `per_instance` tracks each instance separately:

```systemverilog
class agent_cov;
    int agent_id;
    covergroup cg_per_agent;
        option.per_instance = 1;   // Track each agent separately
        option.name = $sformatf("agent_%0d_cg", agent_id);

        cp_addr : coverpoint addr {
            bins low  = { [0:32'h7FFF_FFFF] };
            bins high = { [32'h8000_0000:32'hFFFF_FFFF] };
        }
    endgroup

    function new(int id);
        agent_id = id;
        cg_per_agent = new();
    endfunction
endclass
```

Without `per_instance`, if Agent 0 covers only low addresses and Agent 1 covers only high addresses, the merged report shows 100%. With `per_instance`, you see:

```
agent_0_cg: low=100%, high=0%   → 50%
agent_1_cg: low=0%, high=100%  → 50%
Merged:  low=100%, high=100%    → 100%
```

The per-instance report reveals that each agent has a coverage gap — the merged report hid it.

## type_option — class-level vs instance-level

`type_option` sets options at the CLASS level (affects all instances identically); `option` sets them at the instance level. Common use:

```systemverilog
covergroup cg_global;
    type_option.merge_instances = 0;  // Each instance reported separately (same as per_instance)
    type_option.strobe = 0;           // Count every sample call, not just distinct value changes
endgroup
```

`type_option.merge_instances = 0` is equivalent to `option.per_instance = 1` but set globally.

## A complete example — per-agent AXI coverage

```systemverilog
class axi_agent_cov extends uvm_subscriber #(axi4_lite_write_txn);
    `uvm_component_utils(axi_agent_cov)

    int unsigned agent_id;
    axi4_lite_write_txn cur;

    covergroup cg_axi with function sample(axi4_lite_write_txn t);
        option.per_instance = 1;
        option.at_least     = 5;       // Each bin needs 5 hits

        cp_addr : coverpoint t.awaddr[15:12] {  // 16 address zones
            bins zones[] = { [0:15] };
            option.weight = 2;          // Higher weight — address space is primary
        }

        cp_strb : coverpoint t.wstrb {
            bins full    = { 4'b1111 };
            bins partial = default;
        }

        cx : cross cp_addr, cp_strb {
            option.weight = 3;          // Cross is most important
        }
    endgroup

    function new(string n, uvm_component p);
        super.new(n, p);
        cg_axi = new();
    endfunction

    function void write(axi4_lite_write_txn t);
        cg_axi.sample(t);
    endfunction
endclass
```
