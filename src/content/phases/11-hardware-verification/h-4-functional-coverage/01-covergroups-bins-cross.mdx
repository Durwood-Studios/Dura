## The closure loop

```
Write coverage model → Run random stimulus → Measure coverage →
  Holes? → Refine constraints → Repeat → Closure → Sign-off
```

Coverage closure = every defined coverpoint and cross has been hit at least once. When closure is achieved, verification is "done" by the team's documented criteria.

## A minimal covergroup

```systemverilog
class write_txn;
    rand bit [31:0] addr;
    rand bit [3:0]  strb;
    rand bit [1:0]  size;

    covergroup cg_write;
        cp_addr : coverpoint addr {
            bins low      = { [0           : 32'h0FFF      ] };
            bins mid      = { [32'h1000    : 32'h0FFF_FFFF ] };
            bins high     = { [32'h1000_0000 : 32'hFFFF_FFFF] };
        }

        cp_strb : coverpoint strb {
            bins full   = { 4'b1111 };
            bins partial[] = { [4'b0001 : 4'b1110] };  // 14 individual bins
            bins zero   = { 4'b0000 };
        }

        cp_size : coverpoint size;   // Auto-bins each value

        cx_addr_strb : cross cp_addr, cp_strb;   // 3 × 16 = 48 cross bins
    endgroup

    function new();
        cg_write = new();
    endfunction
endclass

// Sample at the appropriate moment
write_txn tx = new();
repeat (1000) begin
    tx.randomize();
    tx.cg_write.sample();
end

// Coverage report shows what got hit
```

## Bin types

- **Single value**: `bins zero = { 0 };`
- **Range**: `bins small = { [1:255] };`
- **Multi-bin (array)**: `bins each[] = { [1:14] };` creates 14 separate bins
- **Wildcard**: `wildcard bins evens = { 4'b???0 };` matches anything with LSB=0
- **Transition**: `bins seq = ( 0 => 1 => 2 );` triggers when sampled sequence matches
- **Ignore**: `ignore_bins reserved = { 4'b1111 };` doesn't count toward coverage

## Cross coverage

```systemverilog
cx_addr_strb : cross cp_addr, cp_strb;
```

This generates one bin for every combination. 3 addr bins × 16 strb bins = 48 cross bins. Cross coverage finds coverage holes that single coverpoints miss — e.g., "we tested high addresses but never with partial strobes."

Cross bins can be filtered:

```systemverilog
cx_addr_strb : cross cp_addr, cp_strb {
    ignore_bins ig = binsof(cp_strb.zero);   // Never check strb=0 cases
}
```

## Coverage holes — debugging closure

A coverage report shows percentage and lists missed bins. To close:

1. **Identify the missed bin** (e.g., `cp_addr.high × cp_strb.partial` shows 0 hits).
2. **Determine why** — is the constraint biasing away from this? Is it physically impossible? Is the stimulus generator skipping a scenario?
3. **Fix**:
   - Add a `dist` directive to bias toward the missed range.
   - Write a directed-random sequence targeting the case.
   - Mark as `ignore_bins` if genuinely unreachable.

The discipline: every coverage hole is either CLOSED or DOCUMENTED AS UNREACHABLE. Just running more random stimulus doesn't fix structural holes.

## Coverage at the right abstraction

Common mistake: covering implementation details instead of intent. A FIFO depth covergroup should cover:

- Empty, near-empty, half-full, near-full, full
- Transitions between states
- Overflow attempts

NOT:

- Every individual depth value 0-255 (unimportant; bin them)
- Internal pointer values (implementation detail)

The covergroup is a SPEC of what scenarios matter. Engineers who treat it as a "code coverage on internals" miss the point.
