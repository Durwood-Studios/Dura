## Why this matters

The distance reported by a sensor is not all available for stopping. A person and robot can continue moving during detection and control latency, the robot travels while braking, and positions are uncertain. A protective field that ignores any of these can allow the hazard to reach the person before the protective response is effective.

## Start with something familiar

When following a moving vehicle, your stopping space includes travel before you react and travel during braking. If the other object also approaches you, it consumes part of that space too. Robot separation adds detection geometry and measurement uncertainty to this familiar problem.

## The mental model

> Add the distance a person can approach, the robot's reaction travel, its braking travel, and the required intrusion/uncertainty allowances. Measure separation to the nearest relevant hazard, not automatically to the robot base or TCP.

## A traceable distance model

[NIST's SSM implementation study](https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=914783) explains a separation model associated with ISO/TS 15066. Its contributions can be written as:

```text
Sp = Sh + Sr + Ss + C + Zd + Zr
```

Here Sh is human approach during the full reaction-and-stopping period; Sr is robot travel during reaction; Ss is robot braking travel; C accounts for intrusion before detection; Zd and Zr account for person-detection and robot-position uncertainty. The cited paper uses ZS for the person/sensor term. Symbols vary across references: map them explicitly before comparing calculations.

For constant bounding approach speed vh and reaction robot speed vr:

```text
Sh = vh × (Tr + Ts)
Sr = vr × Tr
Sp = vh × (Tr + Ts) + vr × Tr + Ss + C + Zd + Zr
```

Ts is braking time after the defined reaction interval Tr; Ss is corresponding stopping travel from validated evidence. Avoid double-counting controller latency in both times. If speed varies, use justified bounds or the applicable integrated motion model. This lesson's scalar calculation illustrates the budget; apply the governing edition and application requirements before configuring real protective fields.

## Worked example with supplied teaching data

Assume the following **fictional, already bounded inputs**, not specifications for a named robot or scanner:

| Input | Value |
| --- | --- |
| Human approach speed vh | 1.6 m/s |
| Robot speed during reaction vr | 0.6 m/s |
| Total reaction time Tr | 0.10 s |
| Braking time Ts | 0.40 s |
| Robot braking distance Ss | 0.15 m |
| Intrusion allowance C | 0.12 m |
| Detection uncertainty Zd | 0.05 m |
| Robot-position uncertainty Zr | 0.03 m |

```text
Sh = 1.6 × (0.10 + 0.40) = 0.80 m
Sr = 0.6 × 0.10 = 0.06 m
Sp = 0.80 + 0.06 + 0.15 + 0.12 + 0.05 + 0.03 = 1.21 m
```

This result does not establish that 1.6 m/s or C=0.12 m is suitable for a real installation. Approach, detection capability, mounting height, reach and applicable rules determine those assumptions. A narrow aisle or a “walk slowly” sign is not automatically evidence supporting a lower approach speed.

If the detection uncertainty rises from 0.05 to 0.10 m, the calculated separation rises by 0.05 m. If a heavier payload changes both stopping time and distance, update both corresponding terms using appropriate stopping evidence.

## Translate distance into fields carefully

A scalar distance to a hazard does not define a scanner field shape. Locate all relevant robot links, the tool and workpiece over their motion, then assess access directions, reach-over/under, occlusion and sensor limits. Adding an offset to form a radius is valid only for the specified geometry and bounding envelope; a single TCP offset is not a universal field-design rule.

An outer field may request speed reduction and an inner field a stop. If safety relies on reduced speed before the inner boundary, the transition must allow enough distance and time for that reduction, with the reduced speed confirmed by the appropriate protective function. A non-safety warning output alone cannot establish the reduced-speed condition.

Do not calculate the outer warning field solely from a reduced-speed stopping distance and make it smaller than the stop field. The outer transition must be assessed from the speed and state **before** reduction, including human approach and control response. The final field selection needs validation across the required operating states.

## Changes that need review

Revisit the assumptions when speed, payload, tool shape, trajectory, braking behavior, sensor configuration, communication, firmware or layout changes. Some changes may be covered by an existing validated envelope; others require new measurements and validation. Record the configuration and evidence, not merely a number copied from another cell's worksheet.

## What you learned

- Calculate separation using human approach, robot reaction/braking travel, intrusion and uncertainty.
- Explain each contribution and keep time and distance definitions consistent.
- Identify the geometry, sensing and state-transition evidence required for real protective fields.
- Review changed application assumptions before reusing a validated separation calculation.
