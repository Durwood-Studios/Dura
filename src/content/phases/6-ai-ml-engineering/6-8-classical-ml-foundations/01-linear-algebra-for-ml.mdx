## Why this matters

Every ML algorithm you will ever use — linear regression, neural networks, SVMs, PCA — is ultimately a series of linear algebra operations on arrays of numbers. When a model predicts your income from ten features, it is computing a dot product. When a neural network learns to recognize a cat, it is multiplying matrices hundreds of times per forward pass. When someone says a language model has "1024-dimensional embeddings," they mean each token is a point in a 1024-dimensional vector space.

You do not need to prove theorems. You need enough intuition to debug shape errors, understand why two vectors are "similar," and read a paper without losing the thread when it writes **Xw = y**. This lesson builds that intuition from scratch.

## Vectors: lists of numbers with direction

Imagine you are describing a house to a buyer using only numbers: 3 bedrooms, 1400 square feet, 2 bathrooms, built in 1992, priced at $340,000. That list — `[3, 1400, 2, 1992, 340000]` — is a **vector**. In ML, every training example is a vector. Each number is a **feature**, and the vector lives in a space with as many dimensions as you have features.

The length of a vector (its **norm**) tells you how "big" an example is. The angle between two vectors tells you how similar they are. This is not metaphor — it is geometry that happens to live in more than three dimensions.

> **A vector is just a list of numbers that represents a point (or direction) in multi-dimensional space.**

```python
import numpy as np

# A house represented as a feature vector
house = np.array([3, 1400, 2, 1992, 340_000], dtype=float)

# L2 norm: the "length" of the vector
# We normalize to compare houses regardless of price scale
norm = np.linalg.norm(house)
house_normalized = house / norm

print(f"Norm: {norm:.2f}")
print(f"First element normalized: {house_normalized[0]:.6f}")
```

## Dot product: measuring alignment

The dot product of two vectors is the sum of their element-wise products: **a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ**.

Here is the geometric meaning: a high dot product means the vectors point in similar directions. A dot product of zero means they are perpendicular (orthogonal) — completely unrelated. This is why cosine similarity (which normalizes the dot product by the vectors' lengths) measures how similar two things are regardless of their magnitude.

```python
import numpy as np

user_preferences = np.array([0.9, 0.1, 0.8])  # [action, romance, sci-fi]
movie_a = np.array([0.8, 0.2, 0.9])            # heavy sci-fi/action
movie_b = np.array([0.1, 0.95, 0.05])          # pure romance

# Dot product: higher = more aligned with preferences
score_a = np.dot(user_preferences, movie_a)
score_b = np.dot(user_preferences, movie_b)

print(f"Movie A score: {score_a:.3f}")  # High — matches taste
print(f"Movie B score: {score_b:.3f}")  # Low — does not match

# Cosine similarity: normalize first so magnitude doesn't dominate
def cosine_sim(a, b):
    # Divide by both norms so we only measure direction, not length
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

print(f"Cosine similarity A: {cosine_sim(user_preferences, movie_a):.3f}")
```

## Matrices: collections of vectors and linear maps

A **matrix** is a rectangular grid of numbers. In ML it serves two roles:

1. **Data matrix**: each row is one training example (a vector), each column is one feature. A dataset of 1000 houses with 5 features is a 1000×5 matrix.
2. **Transform matrix**: multiplying a vector by a matrix rotates, scales, or projects it into a new space. This is how neural network layers work.

> **A matrix is either a dataset (rows = examples) or a function (input → output).**

```python
import numpy as np

# Dataset: 4 houses, 3 features each
# Rows = examples, columns = [bedrooms, sqft, bathrooms]
X = np.array([
    [3, 1400, 2],
    [4, 2100, 3],
    [2, 900,  1],
    [5, 3200, 4],
])

print("Shape:", X.shape)  # (4, 3) — 4 examples, 3 features

# Matrix as a transform: a projection from 3 features to 1 score
# This is exactly what linear regression does
weights = np.array([50_000, 100, 30_000])  # [$/bedroom, $/sqft, $/bath]

# Matrix-vector multiplication: apply the transform to every example at once
# @ is the matrix multiply operator
prices = X @ weights
print("Estimated prices:", prices)
```

## Matrix multiplication: composing transforms

When you multiply two matrices together, you compose two transformations. **AB** means "first apply B, then apply A." This composability is why neural networks can stack many layers — each layer is a matrix multiply, and stacking them creates complex, non-linear functions (with activation functions in between).

```python
import numpy as np

np.random.seed(42)

# Simulate two neural network layers
# Input: 5 examples, each 3 features
X = np.random.randn(5, 3)

# Layer 1: transform from 3 features → 4 hidden units
W1 = np.random.randn(3, 4)

# Layer 2: transform from 4 hidden units → 1 output
W2 = np.random.randn(4, 1)

# Forward pass: apply both transforms in sequence
# Shapes: (5,3) @ (3,4) = (5,4), then (5,4) @ (4,1) = (5,1)
hidden = X @ W1       # first transform
output = hidden @ W2  # second transform, composed with first

print("Output shape:", output.shape)  # (5, 1) — one prediction per example

# Equivalently in one expression (without activation functions):
output_direct = X @ W1 @ W2
print("Same result:", np.allclose(output, output_direct))
```

## Eigenvectors: directions that survive transformation

When you multiply a matrix by most vectors, the vector changes both direction and length. An **eigenvector** is special: multiplying by the matrix only changes its length (scaled by the **eigenvalue**), never its direction.

This matters enormously for PCA (Principal Component Analysis), which finds the directions of maximum variance in your data. Those directions are the eigenvectors of the data's covariance matrix. If your 100-feature dataset mostly varies along 5 directions, PCA finds those 5 eigenvectors and lets you compress the dataset from 100 to 5 dimensions with minimal information loss.

```python
import numpy as np

# A simple 2D dataset: points scattered diagonally
np.random.seed(0)
# Most variance is along the [1, 1] direction
data = np.random.randn(100, 2)
data[:, 1] = data[:, 0] * 0.9 + np.random.randn(100) * 0.3

# Covariance matrix captures how features vary together
cov = np.cov(data.T)
print("Covariance matrix:\n", cov)

# Eigenvectors of covariance = principal components (directions of max variance)
eigenvalues, eigenvectors = np.linalg.eig(cov)

# Sort by eigenvalue descending (largest = most variance captured)
idx = np.argsort(eigenvalues)[::-1]
eigenvalues = eigenvalues[idx]
eigenvectors = eigenvectors[:, idx]

print(f"\nPrimary eigenvector: {eigenvectors[:, 0]}")  # ~[0.71, 0.71] (≈[1,1] diagonal)
print(f"Variance explained: {eigenvalues[0]/eigenvalues.sum():.1%}")  # ~95%

# Project data onto first principal component (dimensionality reduction)
projected = data @ eigenvectors[:, 0]  # 100 points → 100 scalars
print(f"Reduced from {data.shape[1]}D to 1D, retained ~{eigenvalues[0]/eigenvalues.sum():.0%} variance")
```

## What you learned

- A vector is a list of numbers representing a point in multi-dimensional space; every ML example is a vector.
- The dot product measures alignment between vectors — high dot product means similar direction, which is how recommendation systems score relevance.
- A matrix can be a dataset (rows = examples, columns = features) or a linear transform (the core operation in neural network layers).
- Matrix multiplication composes transforms: stacking two matrices chains two linear maps, which is the mechanics behind deep learning layers.
- Eigenvectors of the covariance matrix are the principal components — the directions of maximum variance that PCA uses for dimensionality reduction.

Next, you will use these linear algebra primitives directly in your first ML model: linear regression treats prediction as a matrix-vector multiplication, and logistic regression adds a nonlinearity to predict probabilities.
