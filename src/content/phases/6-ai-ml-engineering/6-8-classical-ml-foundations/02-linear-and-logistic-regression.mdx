## Why this matters

Every ML interview asks about regression. Every production ML system contains a regression model somewhere. More importantly, the concepts baked into regression — loss functions, gradient descent, regularization, train/test splits — are the same concepts that govern neural networks, gradient-boosted trees, and transformers. If you understand _why_ linear regression works the way it does, you can read the original attention paper and follow the math.

Regression is not a stepping stone to "real" ML. In many production settings — credit scoring, demand forecasting, medical dose estimation — a well-tuned regression beats a neural network because it is interpretable, fast, and robust to overfitting on small datasets. Know when to use it.

## Predicting a continuous number: linear regression

Before naming the model, consider the problem. You have houses: size, bedrooms, age. You want to predict price. The simplest possible relationship is that price scales linearly with each feature: price = w₁·(size) + w₂·(bedrooms) + w₃·(age) + bias.

That is the entire model. It is a weighted sum of features — a dot product between the weights **w** and the feature vector **x**, plus a bias term **b**.

> **Linear regression is just a dot product: ŷ = w · x + b. Training finds the w and b that minimize prediction error across your dataset.**

```python
import numpy as np

# Toy dataset: 5 houses [sqft, bedrooms] → price ($k)
X = np.array([
    [1200, 3],
    [1800, 4],
    [900,  2],
    [2400, 5],
    [1500, 3],
], dtype=float)

y = np.array([240, 360, 180, 480, 300], dtype=float)

# Add a bias column of ones so w·x includes the intercept
# This lets us handle the case where price != 0 when all features are 0
X_b = np.column_stack([np.ones(len(X)), X])  # shape (5, 3)

# Closed-form solution: w = (XᵀX)⁻¹ Xᵀy
# This is the analytic minimum of sum of squared errors
w = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y
print(f"Bias: {w[0]:.1f}, sqft coeff: {w[1]:.3f}, bedroom coeff: {w[2]:.1f}")

# Predict on a new house: 1600 sqft, 3 bedrooms
new_house = np.array([1, 1600, 3])  # 1 for the bias column
prediction = new_house @ w
print(f"Predicted price: ${prediction:.1f}k")
```

## Gradient descent: learning weights iteratively

The closed-form solution above only works when your dataset fits in memory and the matrix inversion is numerically stable. For large datasets and neural networks, we use **gradient descent**: repeatedly nudge the weights in the direction that reduces error.

The intuition: imagine you are blindfolded on a hilly landscape and want to reach the lowest point. You feel the slope under your feet and take a step downhill. Gradient descent does this in weight space — the slope is the gradient of the loss function, and each step is one update.

```python
import numpy as np

# Generate synthetic data: price = 200*sqft_normalized + noise
np.random.seed(42)
n = 100
X = np.random.randn(n, 1)  # normalized sqft
y = 200 * X.squeeze() + np.random.randn(n) * 20  # true relationship + noise

# Initialize weights to zero
w = np.zeros(1)
b = 0.0
lr = 0.1  # learning rate: how big each step is

# Mean Squared Error loss: average of (prediction - truth)²
# We minimize this — when MSE = 0, every prediction is perfect
def mse(y_true, y_pred):
    return np.mean((y_true - y_pred) ** 2)

for epoch in range(200):
    y_pred = X.squeeze() * w[0] + b

    # Gradient: partial derivative of MSE w.r.t. w and b
    # dL/dw = -2/n * sum(x * (y - ŷ))  — how much does loss change if we nudge w?
    # dL/db = -2/n * sum(y - ŷ)         — how much does loss change if we nudge b?
    error = y_pred - y
    grad_w = 2 * np.mean(error * X.squeeze())
    grad_b = 2 * np.mean(error)

    # Step opposite the gradient (downhill)
    w[0] -= lr * grad_w
    b    -= lr * grad_b

    if epoch % 50 == 0:
        print(f"Epoch {epoch}: MSE={mse(y, y_pred):.2f}, w={w[0]:.2f}, b={b:.2f}")

print(f"\nLearned: w={w[0]:.2f} (true=200), b={b:.2f} (true≈0)")
```

## Logistic regression: predicting probabilities

What if you want to predict _whether_ something happens (spam/not-spam, fraud/not-fraud) rather than a continuous value? You need the output to be a probability between 0 and 1.

Linear regression gives you any real number — it could output -500 or 10,000. The **sigmoid function** squashes any number into (0, 1): σ(z) = 1 / (1 + e⁻ᶻ). Apply sigmoid to your linear dot product and you have logistic regression.

> **Logistic regression = linear regression with sigmoid applied to the output. The model still learns a hyperplane; the sigmoid converts the distance from that plane into a probability.**

```python
import numpy as np

def sigmoid(z):
    # Squashes any real number into (0, 1)
    # Large positive z → ~1.0 (high probability)
    # Large negative z → ~0.0 (low probability)
    # z = 0 → exactly 0.5
    return 1 / (1 + np.exp(-z))

# Synthetic binary classification: email is spam (1) or not (0)
# Features: [link_count, exclamation_count]
np.random.seed(0)
n = 200
X_spam    = np.random.randn(n//2, 2) + np.array([3, 4])   # spam: more links/exclamations
X_ham     = np.random.randn(n//2, 2) + np.array([0, 0])   # ham: fewer
X         = np.vstack([X_spam, X_ham])
y         = np.array([1]*(n//2) + [0]*(n//2), dtype=float)

# Initialize weights
w = np.zeros(2)
b = 0.0
lr = 0.1

for epoch in range(300):
    z     = X @ w + b         # linear part
    y_hat = sigmoid(z)        # probability of spam

    # Binary cross-entropy loss (log loss): punishes confident wrong predictions heavily
    # This is the proper loss for probability outputs — not MSE
    loss = -np.mean(y * np.log(y_hat + 1e-8) + (1-y) * np.log(1-y_hat + 1e-8))

    # Gradients for logistic regression — same form as linear regression!
    error  = y_hat - y
    grad_w = X.T @ error / n
    grad_b = error.mean()

    w -= lr * grad_w
    b -= lr * grad_b

    if epoch % 100 == 0:
        acc = ((y_hat > 0.5) == y).mean()
        print(f"Epoch {epoch}: loss={loss:.4f}, accuracy={acc:.2%}")

# Interpret the learned weights
print(f"\nLearned weights: links={w[0]:.2f}, exclamations={w[1]:.2f}")
print("Both positive — more links/exclamations → higher spam probability")
```

## Regularization: preventing overfitting

When you have many features relative to your training examples, the model can memorize the training data perfectly — fitting the noise rather than the signal. This is **overfitting**: the model works on training data but fails on new data.

**L2 regularization** (Ridge) adds a penalty to the loss equal to λ·‖w‖²: the sum of squared weights. This discourages the optimizer from making any single weight very large. The effect: the model is forced to distribute credit across features rather than relying on one feature.

```python
import numpy as np

def train_ridge(X, y, lr=0.01, lam=0.1, epochs=500):
    """
    Train linear regression with L2 regularization (Ridge).
    lam (lambda) controls the strength of the penalty.
    Higher lam → smaller weights → simpler model → less overfitting.
    """
    n, d = X.shape
    w = np.zeros(d)
    b = 0.0

    for _ in range(epochs):
        y_pred = X @ w + b
        error  = y_pred - y

        # Gradient of MSE + L2 penalty
        # The 2*lam*w term shrinks weights toward zero every step
        grad_w = (X.T @ error) / n + 2 * lam * w
        grad_b = error.mean()

        w -= lr * grad_w
        b -= lr * grad_b

    return w, b

# Compare unregularized vs regularized on a tiny dataset with many features
np.random.seed(7)
X_small = np.random.randn(20, 10)     # 20 examples, 10 features
y_small = X_small[:, 0] * 2.0 + np.random.randn(20) * 0.5  # only feature 0 matters

w_plain, _ = train_ridge(X_small, y_small, lam=0.0)   # no regularization
w_ridge, _ = train_ridge(X_small, y_small, lam=0.5)   # strong regularization

print("Unregularized weights:", np.round(w_plain, 2))  # many large, noisy weights
print("Ridge weights:         ", np.round(w_ridge, 2)) # most weights near zero
print(f"\nUnregularized max weight magnitude: {np.abs(w_plain).max():.2f}")
print(f"Ridge max weight magnitude:          {np.abs(w_ridge).max():.2f}")
```

## What you learned

- Linear regression finds weights **w** such that **Xw + b** minimizes mean squared error — it is a dot product trained by gradient descent.
- Gradient descent iteratively nudges weights downhill on the loss surface; the learning rate controls step size.
- Logistic regression adds sigmoid to the output, converting a real number into a probability; log loss is the correct objective.
- L2 regularization penalizes large weights, reducing overfitting when you have many features relative to training examples.
- Model coefficients are interpretable — larger magnitude means that feature has more influence on predictions.

Next, you will build decision trees and random forests — models that find non-linear boundaries without any matrix algebra, and that naturally handle categorical features and missing data.
