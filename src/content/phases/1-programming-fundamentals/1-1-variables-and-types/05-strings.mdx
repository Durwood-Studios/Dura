## Why this matters

Strings are everywhere: usernames, error messages, HTML content, file paths, API responses, log lines. After numbers, strings are the type you will manipulate most.

## Start with something familiar

Imagine receiving a printed sign and ordering an uppercase replacement. The new sign changes the lettering; the original sign remains intact.

## The mental model

> A string is immutable text. Indexes and methods inspect or derive values without rewriting the original string.

## Creating strings

Three syntaxes, one type.

```javascript
const single = 'hello';
const double = "hello";
const template = `hello`;
```

Single and double quotes are interchangeable. Template literals (backticks) are special — they allow **interpolation** and multi-line strings.

```javascript
const name = "Dustin";
console.log(`Hello, ${name}!`); // "Hello, Dustin!"
```

The `${...}` syntax inside backticks evaluates the expression and inserts the result. This replaces clunky concatenation (`"Hello, " + name + "!"`).

## Strings are immutable

Once a string is created, you cannot change its characters in place. Methods that transform text produce a **new** string; inspections can return numbers or booleans instead.

```javascript
const original = "hello";
const upper = original.toUpperCase();
console.log(original); // "hello"  — unchanged
console.log(upper); // "HELLO"  — new string
```

This matters for performance with very large strings, and it means you need to keep the returned result when you want transformed text.

## Length and access

```javascript
const word = "DURA";
console.log(word.length); // 4
console.log(word[0]); // "D"
console.log(word[3]); // "A"
console.log(word.at(-1)); // "A" — .at() supports negative indexes
```

JavaScript length and indexes count UTF-16 code units. A code unit is one piece of the encoding; some visible characters occupy multiple pieces. The ASCII examples here use one code unit per character. Indexes are zero-based. The first character is at index 0, not 1. This convention appears everywhere in programming.

A method is a named operation accessed with a dot; parentheses call it. In the next examples trim removes surrounding whitespace, includes checks containment, indexOf gives the starting index or -1, slice selects a range excluding its end, replace substitutes a match, and split produces an array (an ordered list written with square brackets).

## Common methods

```javascript
const msg = "  Hello, World!  ";
console.log(msg.trim()); // "Hello, World!"
console.log(msg.includes("World")); // true
console.log(msg.indexOf("World")); // 9
console.log(msg.slice(2, 7)); // "Hello"
console.log(msg.replace("World", "DURA")); // "  Hello, DURA!  "
console.log("a-b-c".split("-")); // ["a", "b", "c"]
```

These return new values. They never modify the original string.
