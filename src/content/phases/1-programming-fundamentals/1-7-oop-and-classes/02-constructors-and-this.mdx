## Why this matters

In the last lesson you created objects by calling `new Dog()` and then setting each property one line at a time. That works for two properties — but imagine a class with ten properties. Or imagine creating fifty objects. Manually assigning properties after each `new` is repetitive, error-prone, and easy to forget.

Every serious class you write will use a <VocabTooltip slug="constructor">constructor</VocabTooltip> — a special method that runs automatically the moment you call `new`. It is where initialization happens. Understanding the constructor, and the `this` keyword that makes it work, is the key to writing clean, complete object creation.

## The "assembling at the factory" analogy

Think of the constructor as the assembly line inside a factory. You place an order (call `new`), the factory receives your specifications (the arguments you pass), assembles the product to those specs, and hands you back a finished item ready to use. You do not receive a blank item and then go configure it yourself.

The <VocabTooltip slug="this">this</VocabTooltip> keyword is what each worker on the line uses to refer to the specific item currently being assembled — "attach the engine to _this_ car, not the one next to it."

> **`this` always refers to the specific object the method is running on right now.**

## The constructor method

```javascript
class Dog {
  // constructor runs automatically when you call `new Dog(...)`
  // its parameters become the data for this specific dog
  constructor(name, breed, age) {
    // `this` refers to the new dog object being built right now
    this.name = name;
    this.breed = breed;
    this.age = age;
  }

  bark() {
    // Inside any method, `this` still refers to this specific dog instance
    console.log(`${this.name} says: Woof!`);
  }

  birthday() {
    // Methods can modify properties through `this`
    this.age += 1;
    console.log(`${this.name} is now ${this.age}!`);
  }
}

// Arguments passed to `new Dog(...)` go straight into the constructor
const luna = new Dog("Luna", "Labrador", 3);
const rex = new Dog("Rex", "Beagle", 7);

luna.bark(); // Luna says: Woof!
rex.bark(); // Rex says: Woof!

luna.birthday(); // Luna is now 4!
console.log(rex.age); // 7 — rex is unaffected
```

## What `this` means — and what it does not mean

`this` is not a fixed thing. It is a reference to whichever object called the method.

```javascript
class Counter {
  constructor(start) {
    // Store the starting value on this specific counter instance
    this.count = start;
  }

  increment() {
    // `this` here is the counter that called .increment()
    this.count += 1;
  }

  reset() {
    this.count = 0;
  }

  value() {
    return this.count;
  }
}

const counterA = new Counter(0);
const counterB = new Counter(100);

counterA.increment(); // counterA.count is now 1
counterA.increment(); // counterA.count is now 2
counterB.increment(); // counterB.count is now 101 — counterA is not touched

console.log(counterA.value()); // 2
console.log(counterB.value()); // 101
```

Each method call sets `this` to the object on the left of the dot: `counterA.increment()` makes `this` equal to `counterA`. `counterB.increment()` makes `this` equal to `counterB`.

## Default values in constructors

Constructors can have default parameter values, just like regular functions.

```javascript
class Rectangle {
  // width and height default to 1 if not provided
  constructor(width = 1, height = 1) {
    this.width = width;
    this.height = height;
  }

  area() {
    return this.width * this.height;
  }

  perimeter() {
    return 2 * (this.width + this.height);
  }

  describe() {
    console.log(
      `Rectangle ${this.width}×${this.height}: area=${this.area()}, perimeter=${this.perimeter()}`
    );
  }
}

const square = new Rectangle(5, 5);
const wide = new Rectangle(10, 3);
const unit = new Rectangle(); // uses defaults: 1×1

square.describe(); // Rectangle 5×5: area=25, perimeter=20
wide.describe(); // Rectangle 10×3: area=30, perimeter=26
unit.describe(); // Rectangle 1×1: area=1, perimeter=4
```

## What you learned

- The constructor is a special method that runs automatically when you use `new` to create an object.
- Constructor parameters let you initialize each object with its own data at creation time — no manual assignment needed.
- `this` refers to the specific object instance a method is currently running on.
- Every method call re-evaluates `this` — `a.method()` makes `this` equal to `a`.
- Default parameter values in constructors make some arguments optional while keeping initialization clean.
