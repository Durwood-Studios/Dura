## Why this matters

A supplier's SPC chart showed Cpk = 1.45 for a bearing-race ground diameter — well above the customer's Cpk ≥ 1.33 requirement. The customer auditor asked one more question: "What's your Ppk using long-term data?"

The supplier ran the calculation over six months of production. Ppk = 0.88. The process was locally precise (small within-subgroup variation) but drifting over time — tool wear, grinding-wheel loading, coolant concentration drift. The short-term SPC chart looked good because it detected the within-shift variation; the long-term drift was invisible to operators making real-time adjustments.

The structural point: **Cpk describes the process at its best; Ppk describes what the process actually delivers.** An automotive customer ultimately receives what Ppk describes, not what Cpk describes.

## Common-cause vs special-cause variation

Walter Shewhart's insight, which became the foundation of SPC: all processes have two fundamentally different types of variation.

**Common-cause variation** (also called "chance" or "random" variation):

- Inherent in the process; present all the time.
- Many small independent causes; no single identifiable source.
- Follows a predictable distribution (typically normal for variable data).
- The process is **in statistical control** — operating consistently within its natural variation.
- **Correct response**: change the process system (tooling, setup, design). Investigating individual points in a common-cause system wastes time and destabilizes the process.

**Special-cause variation** (also called "assignable" variation):

- Non-random; caused by something identifiable.
- Tool wear spike, new operator, material lot change, machine malfunction, environment change.
- The process is **out of statistical control** — the distribution is shifting or the variation is increasing.
- **Correct response**: identify and eliminate the assignable cause. Adjust the process back to its natural state.

The control chart's job is to separate these two types. Points within the control limits are common cause; points outside the limits (or patterns that indicate non-randomness) are special cause.

## The X̄–R chart — structure and calculations

The X̄–R chart is a paired chart for variable data with rational subgrouping:

- The **X̄ chart** (top chart) plots the subgroup average — tracks the process center.
- The **R chart** (bottom chart) plots the subgroup range — tracks process spread.

**Control limit calculations:**

First establish: collect at least 25 subgroups. Calculate the overall mean X̄̄ (grand mean) and the average range R̄.

```
X̄ chart:
  UCL_X = X̄̄ + A₂ × R̄
  LCL_X = X̄̄ − A₂ × R̄
  CL_X  = X̄̄

R chart:
  UCL_R = D₄ × R̄
  LCL_R = D₃ × R̄   (= 0 for n ≤ 6)
  CL_R  = R̄
```

Control chart constants for common subgroup sizes:

| Subgroup size n | A₂    | D₃  | D₄    |
| --------------- | ----- | --- | ----- |
| 2               | 1.880 | 0   | 3.267 |
| 3               | 1.023 | 0   | 2.574 |
| 4               | 0.729 | 0   | 2.282 |
| 5               | 0.577 | 0   | 2.114 |

**Worked example:**

Subgroup size n=4. X̄̄ = 10.025mm. R̄ = 0.018mm.

```
UCL_X = 10.025 + (0.729 × 0.018) = 10.025 + 0.013 = 10.038mm
LCL_X = 10.025 − 0.013 = 10.012mm

UCL_R = 2.282 × 0.018 = 0.041mm
LCL_R = 0 (n ≤ 6)
```

The within-subgroup standard deviation σ̂_within is estimated from R̄:

```
σ̂_within = R̄ / d₂

where d₂ = 2.059 for n=4

σ̂_within = 0.018 / 2.059 = 0.00874mm
```

This is **σ_within** — the short-term process standard deviation — used for Cpk.

## Capability indices — the four you must know

**Cp — potential capability (spread ratio, ignores centering):**

```
Cp = (USL − LSL) / (6 × σ_within)
```

Cp answers: if the process were perfectly centered, what would the defect rate be? Cp ignores whether the process is actually centered on the target.

**Cpk — actual short-term capability (centering-adjusted):**

```
Cpk = min( (USL − X̄̄) / (3 × σ_within),  (X̄̄ − LSL) / (3 × σ_within) )
```

Cpk answers: given where the process is currently centered AND its short-term spread, what is the short-term defect rate? Cpk ≤ Cp always; they're equal only when the process is perfectly centered.

**Pp — long-term potential (uses overall σ):**

```
Pp = (USL − LSL) / (6 × σ_overall)
```

where σ_overall is the standard deviation of ALL individual measurements (not subgroup-based). σ_overall includes both within-subgroup variation AND between-subgroup (drift) variation.

**Ppk — actual long-term performance:**

```
Ppk = min( (USL − X̄̄_total) / (3 × σ_overall),  (X̄̄_total − LSL) / (3 × σ_overall) )
```

**The relationship Cpk vs Ppk:**

σ_within ≤ σ_overall always. Therefore Cpk ≥ Ppk always.

The gap between Cpk and Ppk is the diagnostic for long-term drift:

- **Cpk ≈ Ppk**: stable process; within-subgroup and between-subgroup variation are similar; what you see intrashift is what you get over months.
- **Cpk >> Ppk**: significant long-term drift; the process is locally precise but shifts over time (tool wear, setup-to-setup variation, material lot differences, seasonal effects). This is the most common pattern in production and the most dangerous to miss.

AIAG PPAP thresholds:

- Initial process study (new launch): **Ppk ≥ 1.67**
- Ongoing production: **Cpk ≥ 1.33**

These are different numbers because the Ppk threshold is higher — the customer requires long-term demonstrated performance at launch, not just in-control short-term capability.

## Nelson rules — detecting non-random patterns

Beyond single points outside control limits, several non-random patterns indicate special causes even when all points are within the limits. The standard reference is Nelson (1984) / Western Electric statistical quality control rules:

| Rule | Pattern                                                 | Signal                                                   |
| ---- | ------------------------------------------------------- | -------------------------------------------------------- |
| 1    | 1 point beyond 3σ                                       | Single major shift or outlier                            |
| 2    | 9 points in a row on same side of CL                    | Sustained mean shift                                     |
| 3    | 6 points in a row steadily increasing or decreasing     | Process drift (e.g., tool wear)                          |
| 4    | 14 points in a row alternating up and down              | Over-adjustment ("hunting")                              |
| 5    | 2 of 3 consecutive points beyond 2σ same side           | Sustained minor shift                                    |
| 6    | 4 of 5 consecutive points beyond 1σ same side           | Sustained minor shift                                    |
| 7    | 15 points in a row within 1σ of CL both sides           | Reduced variation (check for measurement stratification) |
| 8    | 8 points in a row beyond 1σ both sides no points inside | Bimodal distribution (two populations mixed)             |

Rule 3 (6 points trending) is particularly important in machining: it detects tool wear before a point goes outside the UCL or LCL. An operator who adjusts the tool when Rule 3 fires prevents scrap rather than producing a rejection.

## In control but not capable; capable but not in control

The two-by-two grid that manufacturing engineers must internalize:

|                              | In statistical control                                                                                       | Out of statistical control                                                                    |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| **Capable (Cpk ≥ 1.33)**     | Ideal state. Predictable, defect-rate meets spec.                                                            | Capable when in control but having special causes. Fix the assignable causes.                 |
| **Not capable (Cpk < 1.33)** | Stable but systematically producing defects. Requires system-level improvement (design, tooling, materials). | Both problems at once — highest priority. Start with special causes, then address capability. |

The most common error: treating a capable-but-not-in-control process as "fine because Cpk is good." The special causes will eventually drive the process out of spec — the current Cpk is not a reliable predictor because the process is not stable.
