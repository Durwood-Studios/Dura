## Why this matters

A dashboard can show a plausible number that represents the wrong machine, unit, or time. A successful network connection does not prove a correct manufacturing data integration. The receiving system needs enough context to distinguish a real zero from a missing or stale observation.

## Start with something familiar

Translating a weather report requires more than copying '32.' The recipient needs Fahrenheit or Celsius, the place, and when the reading was taken. An industrial bridge is also a translator of meaning, with delivery behavior layered underneath.

## The mental model

> An information model defines what an observation means; a protocol carries it; timing and security requirements govern how the complete system may use it.

## Three different concerns

MTConnect defines manufacturing data semantics and structured machine observations. OPC UA supplies an information-model and communication framework; the joint MTConnect companion specification maps MTConnect concepts into OPC UA. A companion specification is an agreed domain model, not proof that two installed products support the same revision or every optional capability.

Time-sensitive networking (TSN) concerns Ethernet timing and traffic behavior. IEC/IEEE 60802 addresses a TSN profile for industrial automation. Neither the words TSN nor OPC UA establish an end-to-end latency bound by themselves. A bound requires a stated traffic model, network configuration, clock assumptions, device behavior, and verification of the deployed system. Do not confuse a manufacturing data bridge with a safety control channel.

## A mapping contract

For a spindle-speed observation, preserve the device identity, data-item identity, value and unit, source timestamp, and validity information. Track sequence or continuity information when the source provides it. A consumer may also record receipt time, but receipt time must not replace source time without an explicit distinction.

If the source says unavailable, do not publish a normal-quality zero: zero could mean a stopped spindle. If the connection restarts and continuity cannot be proven, expose the gap and reacquire the appropriate state. Historical observations should not masquerade as fresh samples.

## Worked record

Our teaching source record is device MILL-4, item spindle-speed, value 1200, unit revolutions/minute, source time 10:00:00Z, sequence 41. The bridge receives it at 10:00:02Z. A mapping table records these identities and units unchanged and separately records the two-second delivery age. A later unavailable observation updates validity and does not fabricate a speed.

These record names are a teaching contract, not a complete MTConnect XML or OPC UA implementation. Production mapping must use the actual specification's node types and status behavior, configured certificates and trust, access permissions, and tested error handling. A read-only observation flow should not acquire write or control permissions merely because the destination protocol can support them.
