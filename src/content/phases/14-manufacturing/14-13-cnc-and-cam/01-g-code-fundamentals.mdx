## Why this matters

A coordinate is meaningful only with its active units, coordinate system, and motion mode. Reading a CNC program one line at a time without carrying that state can conceal a wrong destination or an inappropriate retract. This lesson teaches a desk review, not an authorized machine setup.

## Start with something familiar

Directions such as 'go to house 12' and 'move twelve houses forward' sound similar but have different meanings. A machine program also needs to distinguish a destination from a displacement, and remember which interpretation remains active.

## The mental model

> A G-code block updates controller state and may request motion. Interpret each coordinate using the active modes and verified setup; a short preamble cannot prove physical clearance.

## Read words and state

A block is a line of program words. In the milling dialect illustrated here, G90 selects absolute coordinates and G91 incremental coordinates; G0 requests rapid positioning and G1 linear feed motion. Axis words such as X specify positions or displacements under the active mode. G20 and G21 select inches and millimetres. Actual controller behavior must be checked in its manual.

For this paper exercise, assume millimetres, a fixed work coordinate system, initial X=2, and linear feed mode already active. No physical motion is requested by this page. The following is an incomplete instructional fragment, not a machine-ready program:

```text
G90 X5
G91 X3
X-1
G90 X2
```

The successive X coordinates are 5, 8, 7, and 2. The second line adds 3 to 5; it is not an alternative version of the first line. The third inherits incremental mode. The fourth returns to absolute interpretation.

## Coordinates are not setup verification

A work offset locates the part coordinate system relative to the machine reference. A tool length offset accounts for the selected tool geometry according to the controller's conventions. G43 does not measure a tool or establish the part surface by itself. Incorrect offset values can produce incorrect physical positions even when the program's arithmetic is consistent.

A preamble can explicitly set selected modes, but it does not reset every machine state or establish fixture clearance. Units, distance and feed modes, work offsets, tool compensation, spindle state, and cycle state need the setup's defined treatment. Avoid assuming that a mode-setting line is universally free of side effects or takes exactly zero time.

## Canned cycles carry more state

A canned drilling cycle such as G81 abbreviates a defined sequence. In the Haas milling model, G98 and G99 select initial-point and R-plane return behavior respectively. A statement that every hole always retracts to R ignores this distinction. Initial position, R plane, depth, and fixture height all affect a clearance review. Cycle repetition, cancellation, arc-centre interpretation, and feed units also depend on the applicable controller and modes.

A teaching parser that ignores offsets, arcs, unsupported codes, or return modes cannot validate machine safety. When the necessary state is unknown, record an unresolved review item rather than invent a safe position.
