## Why this matters

A factory with a red-tag event, shadow boards, and labeled floor lanes is a factory that looks Lean. A factory where operators know exactly what to do, in what order, in how much time, with what materials — and where the workspace enforces that knowledge visually — is a factory that IS Lean. The gap between looking and being comes down to whether 5S was anchored to Standard Work.

The ISO 9001:2015 audit finding you want to avoid is §8.5.1 (production under controlled conditions) citing "no documented work instructions at the point of use." 5S events create the environment; Standard Work creates the documentation. Both are needed; neither alone is enough.

## The five 5S phases

The five phases are sequential and interdependent. Each produces a documented output; without the output, the phase cannot be audited.

### S1 — Sort (Seiri)

Remove everything from the work area that is not needed for the current production. "Needed" means needed in the current process step, by the current operator, today.

**Implementation:** Red-tag campaign. Any item whose necessity is uncertain gets a red tag with a date. Red-tagged items move to a quarantine area. Items not reclaimed within 30 days are disposed of per a documented disposition procedure.

**Output:** Red-tag log (items tagged, disposition, date). This is the audit record for Sort.

The Sort rule: when in doubt, remove it. Unnecessary items are waste (motion waste searching for things, overprocessing waste using the wrong tool, inventory waste storing items not needed). Removing something that turns out to be needed is recoverable in hours; keeping unnecessary items costs productivity every day.

### S2 — Set in Order (Seiton)

Arrange necessary items for easiest use. "Everything has a place; everything is in its place."

**Implementation:** Shadow boards for hand tools (the tool's silhouette on the board shows exactly where it belongs and when it's missing). Floor tape and labels for material locations. Labeling cabinets and bins with the specific item and quantity range. Ergonomic placement: most-used items closest to the operator's normal position.

**Output:** Area layout diagram with labeled locations for every item. This is what sustain audits check against.

**Key principle:** placement should enforce the optimal work sequence. If the correct work sequence is tool A → tool B → component C, then tool A should be nearest to the operator, B second, C third. Set in Order makes wrong sequence harder than right sequence.

### S3 — Shine (Seiso)

Clean the work area to a specified, documented standard. Find problems while cleaning.

**Implementation:** Assign specific cleaning tasks to specific operators on a documented schedule. Include equipment inspection in the cleaning routine: checking for leaks, loose fasteners, worn guards, abnormal noise. Cleaning IS inspection.

**Output:** Cleaning schedule with task list, responsible operator, and frequency. Inspection checklist embedded in the cleaning procedure.

The Jidoka connection: Shine is how abnormalities (leaks, wear, damage) are detected early. A dirty machine hides problems; a clean machine surfaces them at the earliest point.

### S4 — Standardize (Seiketsu)

Document the output of S1–S3 so that the improved state is reproducible and auditable.

**Implementation:** Visual standards — photographs of the correct state for each area, posted at the area. Audit checklists that reference the documented standard. Assign ownership for each area with a named responsible person.

**Output:** 5S standards for the area (visual aids, photographs, ownership list, audit checklist). This is the document set that makes S5 possible.

### S5 — Sustain (Shitsuke)

Maintain the improved state through habitual discipline and periodic audit.

**Implementation:** Scheduled 5S audits against the S4 standard (weekly, or more frequently in high-traffic areas). Audit results posted visibly in the area. Trending of scores over time. Kaizen response to declining scores before they reach a threshold that requires a full re-event.

**Output:** 5S audit log with scores and trend. Corrective-action log for findings.

The failure mode: 5S events but no sustain. The floor improves for a few weeks, then slides back. Without scheduled audits against a documented standard, there is no signal that the improvement is decaying and no trigger to correct it.

## Standard Work — the what and why

<VocabTooltip slug="standard-work-sheet">Standard Work Sheet</VocabTooltip> (SWS) is the documented
current-best-known-method for a specific workstation. It captures three things:

1. **Takt time** — how fast the customer needs the work done. Takt = (net available production time) / (customer demand in units per shift). If net available time is 27,000 seconds/shift and demand is 270 units/shift, takt is 100 seconds/unit. The operator's cycle time target is ≤ takt.

2. **Work sequence** — the optimal order of operations. Documented step by step, with quality checks explicitly placed in the sequence (not as an afterthought). The sequence is optimized by observing the actual work, timing each element, and eliminating motion waste.

3. **Standard WIP** — the minimum in-process inventory that keeps the work flowing without overproduction. On an assembly line, standard WIP might be one unit between each workstation to buffer against minor variation without permitting runaway overproduction.

### Standard Work Sheet structure

```
┌──────────────────────────────────────────────────────────┐
│ STANDARD WORK SHEET                                      │
│ Area: Final Assembly Station 3     Date: 2026-06-30      │
│ Part: Relay Module 4400-K          Rev: C                │
│ Takt Time: 100 seconds/unit                              │
├────┬─────────────────────────────┬────────┬─────────────-┤
│ #  │ Operation                   │ Time   │ Quality Check│
├────┼─────────────────────────────┼────────┼──────────────┤
│ 1  │ Pick relay from bin A3      │  5 s   │              │
│ 2  │ Verify part number label    │  3 s   │ ✓ Label match│
│ 3  │ Insert into housing slot 1  │ 12 s   │              │
│ 4  │ Torque cover bolt M4×0.7   │  8 s   │ ✓ Torque tag │
│ 5  │ Connect harness connector   │  7 s   │ ✓ Click heard│
│ 6  │ Place unit on conveyor      │  4 s   │              │
├────┴─────────────────────────────┴────────┴──────────────┤
│ Total cycle: 39 s     Standard WIP: 1 unit upstream      │
│ Operator: _____________ Supervisor: _______________      │
└──────────────────────────────────────────────────────────┘
```

The SWS lives at the workstation — posted visibly, on a board, in a clear cover. It is not in a binder in the quality office. It is the work instruction the operator refers to and that supervisors coach against.

### Why "without a standard, there can be no Kaizen"

Toyota's framing is structural. If a work method is not documented:

- You cannot tell whether an operator is following the best method or improvising.
- You cannot measure whether a Kaizen improvement produced better performance (no baseline to compare).
- You cannot train a new operator to the current best method.
- You cannot sustain an improvement through operator turnover.

The SWS is the baseline. Every Kaizen event's output is a REVISED SWS. The improvement is not real until the SWS is updated. The updated SWS IS the improvement.

## Tying 5S to Standard Work

5S and Standard Work are not separate programs — they are two aspects of the same foundation:

| 5S Phase     | Standard Work tie-in                                                   |
| ------------ | ---------------------------------------------------------------------- |
| Set in Order | The tool layout enforces the documented work sequence                  |
| Shine        | The cleaning checklist checks the equipment the SWS depends on         |
| Standardize  | The 5S standard IS the physical infrastructure the SWS assumes         |
| Sustain      | 5S audit scores track whether the SWS's physical context is maintained |

An operator following the SWS in a Set-in-Order-compliant workstation has the right tools in the right place in the right sequence. An operator following the SWS in a disordered workstation must improvise the physical aspects — and the SWS's documented cycle time becomes unachievable.

## What's next

Lesson M4-4 covers Kanban and pull systems — the mechanism that implements Just-In-Time production. Where Standard Work documents what happens at a single workstation, Kanban orchestrates the flow of material between workstations, triggering production only when downstream signals demand. The two are complementary: Standard Work defines how fast each station runs; Kanban defines when and what to produce.
