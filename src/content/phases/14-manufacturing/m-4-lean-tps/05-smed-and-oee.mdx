## Why this matters

In 1950, Shigeo Shingo observed that changing a press die at Toyota took four hours. The natural response was to produce in large batches — one changeover, a large run. Large batches create large WIP, long lead times, and slow feedback on defects. Shingo's insight was that changeover time is not a fixed cost of the process; it is an artifact of undifferentiated setup work that can be systematically reduced. By 1969, Shingo reduced the same press's changeover time to three minutes — a name he coined "Single-Minute Exchange of Die."

The business case: if changeover takes 3 minutes instead of 4 hours, a line can profitably change over every hour to serve different customer demand. Lot sizes shrink. Lead times shrink. Pull systems become viable across a full product mix. The math connecting changeover time to optimal lot size is explicit in economic lot sizing — SMED is the lever that pulls lot size toward one.

## SMED — the four-step method

### Step 1: Observe and record the current changeover

Video the current changeover. Record every activity from the moment the last part of the old run is made to the moment the first good part of the new run is made. Time each activity. Do not "optimize" during observation — see what actually happens.

**Why video?** Verbal descriptions of changeover activities are incomplete and biased toward "the way it should be done." Video captures what actually happens, including waste that operators have normalized.

### Step 2: Separate Internal from External setup

The load-bearing distinction in SMED:

> **Internal setup** — activities that can ONLY be done while the machine is stopped. The machine must be off to do these.
> **External setup** — activities that CAN be done while the machine is running, before the changeover begins or after it ends.

Examples:

- Fetching tools and materials: **external** (can be done during the prior run)
- Removing the old die: **internal** (machine must be stopped)
- Cleaning the die after removal: **external** (can be done off-machine in parallel)
- Installing the new die: **internal** (machine must be stopped)
- Pre-heating the new die: **external** (can be done during prior run in a warming station)
- Documenting the changeover: **external** (can be done after machine restarts)

The impact of this separation: activities classified as external are moved OUTSIDE the machine-stopped window. Only internal activities count toward changeover time. In Shingo's original study, this single step (reclassifying external activities) reduced changeover time by 30–50% without changing any process.

### Step 3: Convert Internal to External where possible

For each remaining internal activity, ask: "Is there anything preventing this from being done before the machine stops?" Common conversions:

- **Pre-setting** — configure the new tool/die/setup OFF the machine to documented specifications before it needs to be installed. Use a standard setup sheet so the pre-setter doesn't have to figure out settings during the installation window.
- **Parallel setup** — use a second operator to execute concurrent internal activities. Two operators changing dies on opposite sides of a press simultaneously; the parallel work appears only once in the elapsed time.
- **Quick-connect fasteners** — replace multi-bolt flanges with cam-lock or bayonet connectors. Converting from 16 individual bolts to 4 quick-lock clamps reduces fastening time from 8 minutes to 45 seconds.

### Step 4: Streamline all remaining internal activities

For the irreducible internal activities, apply motion economy: eliminate reaching, walking, searching. Layout the installation sequence so tools are in sequence order, not scattered. Use ECRS (Eliminate, Combine, Rearrange, Simplify) on each step.

**SMED result targets:** The original SMED name implies sub-10 minutes. Modern SMED targets are more nuanced — the objective is to reduce changeover until it is not the limiting factor in lot-size reduction. A 2-hour changeover reduced to 10 minutes enables lot sizes of 50 instead of 500. Further reduction to 2 minutes enables lot sizes of 10. The target is driven by the desired lot size, which is driven by the customer's demand frequency.

## OEE — the three-factor effectiveness formula

<VocabTooltip slug="oee">Overall Equipment Effectiveness</VocabTooltip> quantifies how much of a
machine's planned production capacity is actually converted into good output:

```
OEE = Availability × Performance × Quality

Availability = Actual Production Time / Planned Production Time
Performance  = (Ideal Cycle Time × Total Units Produced) / Actual Production Time
Quality      = Good Units / Total Units Produced
```

### Worked OEE calculation

A machining center has the following data for one 8-hour shift:

- Planned production time: 480 minutes (full 8-hour shift)
- Unplanned downtime: 45 minutes (tool breakage, waiting for material)
- Actual production time: 480 − 45 = **435 minutes**
- Ideal cycle time: 2.0 minutes/part (per supplier specification at optimal conditions)
- Total units produced: 190 parts
- Defective units: 8 parts (scrap + rework required)
- Good units: 190 − 8 = **182 parts**

```
Availability = 435 / 480 = 0.906 = 90.6%

Performance  = (2.0 min/part × 190 parts) / 435 min
             = 380 / 435 = 0.874 = 87.4%

Quality      = 182 / 190 = 0.958 = 95.8%

OEE = 0.906 × 0.874 × 0.958 = 0.758 = 75.8%
```

The machine produced good output for only 75.8% of its planned time — even though it was only unplanned-down for 45 minutes of the 480-minute shift. The multiplicative nature of OEE is the structural insight: each factor's inefficiency multiplies into the total; improving only one factor while neglecting others limits the gain.

### The Six Big Losses

The Six Big Losses (defined by Seiichi Nakajima's Total Productive Maintenance framework) map directly to OEE factors:

| Factor       | Loss                                               | Example                                                             |
| ------------ | -------------------------------------------------- | ------------------------------------------------------------------- |
| Availability | Equipment failure (unplanned downtime)             | Machine breakdown, tool breakage                                    |
| Availability | Setup and adjustment (planned changeover)          | Changeover time — SMED target                                       |
| Performance  | Minor stops (< 10 minutes, excluded from downtime) | Jams, sensor trips, quick-clear                                     |
| Performance  | Reduced speed                                      | Running below ideal cycle time due to worn tooling, operator pacing |
| Quality      | Startup scrap                                      | First parts after changeover until process stabilizes               |
| Quality      | Production defects                                 | In-cycle rejects and rework                                         |

SMED directly attacks the second Availability loss (setup and adjustment). TPM (Total Productive Maintenance) attacks equipment failures and minor stops. Process capability work (SPC, FMEA) attacks Quality losses.

### The ISO 22400 caveat (restated from M10)

ISO 22400 standardizes OEE vocabulary but explicitly allows plant-specific assumptions about what counts as planned production time, what is "unplanned downtime" vs "minor stops," and whether ideal cycle time is the supplier's specification or the plant's historical average. Two plants both "correctly" computing OEE can report different numbers.

The professional practice: always state your assumptions when reporting OEE. "OEE = 75.8%; planned time excludes scheduled PM; ideal cycle time = 2.0 min/part per supplier spec; Quality = first-pass yield." Without the assumptions, the number is uninterpretable.

## The connection between SMED and OEE

Changeover time (SMED target) appears in OEE as an Availability loss. On a machine that changeovers twice per shift for 60 minutes each:

- Without SMED: Availability loss = 120 min / 480 min = 25%
- With SMED (10-minute changeovers): Availability loss = 20 min / 480 min = 4.2%

The OEE impact of SMED: a 10-minute changeover on a machine that formerly took 60 minutes adds 50 minutes of productive time per changeover. If the machine changeovers twice per shift, that's 100 additional productive minutes per shift — a 20.8% Availability gain before any other improvement.

{`// OEE Calculator and Six Big Losses Analyzer
// Given shift production data, calculate OEE and identify the dominant loss

function calculateOEE(shiftData) {
const {
plannedProductionMinutes,
unplannedDowntimeMinutes,
changeoverMinutes, // included in downtime — SMED target
idealCycleTimeMinutes, // per-unit ideal
totalUnitsProduced,
defectiveUnits,
} = shiftData;

// Actual production time excludes ALL downtime (unplanned + changeover)
const totalDowntime = unplannedDowntimeMinutes + changeoverMinutes;
const actualProductionMinutes = plannedProductionMinutes - totalDowntime;
const goodUnits = totalUnitsProduced - defectiveUnits;

const availability = actualProductionMinutes / plannedProductionMinutes;
const performance = (idealCycleTimeMinutes _ totalUnitsProduced) / actualProductionMinutes;
const quality = goodUnits / totalUnitsProduced;
const oee = availability _ performance \* quality;

return {
actualProductionMinutes,
totalDowntime,
goodUnits,
availability,
performance,
quality,
oee,
// Contribution of each factor to total OEE loss
availabilityLoss: 1 - availability,
performanceLoss: 1 - performance,
qualityLoss: 1 - quality,
};
}

// Current state
const current = {
plannedProductionMinutes: 480,
unplannedDowntimeMinutes: 35,
changeoverMinutes: 90, // 3 changeovers × 30 min each
idealCycleTimeMinutes: 1.5,
totalUnitsProduced: 220,
defectiveUnits: 12,
};

// After SMED — same data but changeovers reduced from 30 min to 8 min each
const afterSmed = {
...current,
changeoverMinutes: 24, // 3 changeovers × 8 min each

};
