## Engineering judgment practice

Eight versioned cases span data integrity, release decisions, accessibility, AI, embedded sensing, market-data correctness, robotics escalation and maintenance economics. Learners record evidence, uncertainty, tradeoffs, relevant source scope, measurable validation and stop conditions. The initial decision is preserved before new evidence is revealed; learners revise, compare a worked example, self-review against six anchored dimensions and return for delayed practice. The encrypted journal, portable export, printable teacher guide and source links are included.

Sources include SWEBOK v4, ABET 2026–2027 outcomes, WCAG 2.2, NIST AI RMF, ACM ethics and the IES/WWC learning guide. The published teaching recommendations inform the design; Dura-specific effectiveness and the rubric's reliability have not been established. See [the feature contract](standards/engineering-judgment/ej-1.0.md) for evidence levels and evaluation requirements.

## Viewport and offline acceptance

Standards and vocabulary popovers use portal positioning, collision detection and viewport-constrained scrollable panels. Fixed consent, storage, feedback, search, install and update surfaces are bounded for narrow and short screens. The full offline package includes authored lessons, judgment cases, lab instructions and downloadable source bundles. A failed page must abort the new package while preserving the previous complete package.

Chromium checks exercise every phase lesson, tutorial, how-to guide and phase/module navigation page at 320 pixels, plus short landscape, resizing and keyboard dismissal. Selected critical workflows also run in Firefox and mobile WebKit. These checks establish the tested cases, not a universal guarantee across every browser, zoom level and assistive technology.

The final clean 749-lesson, 1,806-question, eleven-project production build has passing evidence for all 52 browser scenarios. One complete run passed 51 scenarios; mobile WebKit paused during a journal button's stability check and the unchanged traced rerun passed in 4.3 seconds. This is 51 full-run passes plus one targeted pass, not a single clean 52-test run. All 749 lessons and every guide/curriculum-navigation batch passed in that final full run. The complete offline download opened a never-visited final lesson with networking disabled; written responses and Discovery stamps survived reload and appeared in the downloaded archive.

Firefox’s Playwright `page.reload()` command hit an injected Juggler frame error under the service worker and Cross-Origin-Opener-Policy. Two complete Firefox journal workflows instead passed using browser-native `location.reload()` (3.1 and 3.0 seconds), asserting an active service-worker controller after each reload. Chromium and mobile WebKit retain the ordinary driver reload. No security header or service-worker support was disabled. The final rebuilt snapshot also passed the Firefox workflow (3.6 seconds) with the same browser-native reload and controller checks; security headers and service-worker support remained enabled.
